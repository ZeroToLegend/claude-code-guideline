markdown
# CLAUDE.local.md

Ghi chú **riêng của bạn** cho một dự án. File này nằm ở gốc dự án, được nạp cùng `CLAUDE.md` và được đối xử y hệt, nhưng không commit lên git. Đồng đội không thấy nó.

## Bắt đầu nhanh

1. Tạo file `CLAUDE.local.md` ở gốc dự án (hoặc chạy `/init` và chọn tuỳ chọn cá nhân)
2. Viết những chỉ dẫn chỉ đúng với bạn: URL sandbox, tài khoản test, thói quen làm việc
3. Thêm `CLAUDE.local.md` vào `.gitignore`. `/init` với tuỳ chọn cá nhân làm việc này giúp bạn

```markdown
# Ghi chú cá nhân

- Môi trường dev của tôi: http://localhost:5173, API ở http://localhost:8080
- Tài khoản test: tester01 / dữ liệu mẫu trong `fixtures/me.json`
- Tôi thích review từng file một, đừng sửa nhiều file trong một lượt
```

## Thứ tự nạp

Trong mỗi thư mục, `CLAUDE.local.md` được nối **sau** `CLAUDE.md`, nên ghi chú cá nhân là thứ cuối cùng Claude đọc ở cấp đó. Nếu hai file nói khác nhau, câu trong file local là câu Claude đọc sau cùng.

| Cấp | Vị trí | Dùng chung với |
|---|---|---|
| Managed policy | Đường dẫn hệ thống do IT quản lý | Mọi người trong tổ chức |
| Người dùng | `~/.claude/CLAUDE.md` | Chỉ bạn, mọi dự án |
| Dự án | `./CLAUDE.md` hoặc `./.claude/CLAUDE.md` | Cả nhóm qua git |
| **Local** | `./CLAUDE.local.md` | **Chỉ bạn, dự án này** |

## Lưu ý với worktree

File `CLAUDE.local.md` đã gitignore chỉ tồn tại trong worktree nơi bạn tạo nó. Nếu làm việc trên nhiều [worktree](^Thư mục làm việc riêng của git, có file và nhánh riêng nhưng dùng chung lịch sử repository) của cùng một repo, hãy import một file trong thư mục home thay vì chép lại:

```markdown
# Sở thích cá nhân
- @~/.claude/my-project-instructions.md
```

## Mẹo

- Dùng `CLAUDE.local.md` cho thứ thuộc về **bạn**, `CLAUDE.md` cho thứ thuộc về **dự án**
- File bị bỏ qua nếu bạn loại `local` khỏi cờ `--setting-sources`
- Cũng như CLAUDE.md, không ghi secret hay mật khẩu vào đây. File không commit nhưng vẫn nằm dạng văn bản thuần trên máy

Dynamic Workflows là gì?

Điều phối hàng chục subagent bằng một script; khác gì subagent, skill và agent team.

File liên quan

Dynamic Workflows

Dynamic workflow là một script JavaScript điều phối nhiều subagent cùng lúc. Claude viết script cho việc bạn mô tả, một runtime chạy nó dưới nền trong khi phiên của bạn vẫn dùng được. Script lưu trong .claude/workflows/ trở thành một lệnh /<tên> để chạy lại về sau.

Dùng workflow khi việc cần nhiều agent hơn một cuộc hội thoại điều phối nổi, hoặc khi bạn muốn quy trình điều phối được ghi thành script để đọc và chạy lại: quét bug toàn codebase, migrate 500 file, nghiên cứu cần đối chiếu nhiều nguồn.

Bắt đầu nhanh

  1. Thử workflow có sẵn: /deep-research <câu hỏi>
  2. Hoặc thêm từ khoá ultracode vào prompt (hay nói "dùng workflow") để Claude viết workflow cho việc của bạn
  3. Duyệt kế hoạch khi được hỏi, rồi theo dõi bằng /workflows
  4. Chạy ổn thì mở /workflows, chọn lượt chạy, nhấn s để lưu thành lệnh
text
ultracode: kiểm tra mọi API endpoint trong src/routes/ xem có thiếu kiểm tra xác thực không

Có trên mọi gói trả phí, Anthropic API, Amazon Bedrock, Google Cloud và Microsoft Foundry. Với gói Pro, bật ở dòng Dynamic workflows trong /config.

Workflow khác gì các cách khác

Subagent Skill Agent team Workflow
Là gì Worker Claude sinh ra Chỉ dẫn Claude làm theo Agent trưởng giám sát các phiên ngang hàng Script do runtime chạy
Ai quyết định bước tiếp Claude, từng lượt Claude, theo prompt Agent trưởng, từng lượt Script
Kết quả trung gian nằm ở Context window của Claude Context window của Claude Danh sách việc chung Biến trong script
Lặp lại được gì Định nghĩa worker Chỉ dẫn Định nghĩa team Chính quy trình điều phối
Quy mô Vài việc mỗi lượt Như subagent Vài phiên chạy lâu Hàng chục tới hàng trăm agent mỗi lượt chạy

Điểm mấu chốt: workflow chuyển kế hoạch vào code. Script giữ vòng lặp, rẽ nhánh và kết quả trung gian, nên context của Claude chỉ chứa câu trả lời cuối. Nó cũng áp được khuôn mẫu chất lượng lặp lại, như cho các agent độc lập phản biện phát hiện của nhau trước khi báo cáo.

Cách Khi nào

Từ khoá chỉ có tác dụng trong prompt bạn tự gõ. Nó không kích hoạt từ prompt -p, tác vụ lên lịch, hay nội dung webhook và comment PR được chuyển vào hội thoại. Bỏ highlight cho prompt hiện tại bằng Option+W (macOS) hoặc Alt+W.

Chế độ quyền Khi nào bị hỏi

Hộp thoại hiện các phase dự kiến. Chọn View raw script hoặc nhấn Ctrl+G để đọc script trước khi quyết định. Subagent do workflow sinh ra vẫn tuân theo rule quyền của bạn.

Nhấn s trong /workflows và chọn nơi lưu:

Vị trí Phạm vi
.claude/workflows/ Dự án, dùng chung với người clone repo
~/.claude/workflows/ Mọi dự án, chỉ mình bạn

Giới hạn Lý do

Chi phí

Một lượt chạy sinh nhiều agent nên có thể tốn token hơn hẳn so với làm trong hội thoại. Thử trên phạm vi nhỏ trước (một thư mục thay vì cả repo). Khi workflow dự kiến quá 25 agent hoặc 1,5 triệu token, Claude Code hiện cảnh báo Large workflow. Đặt mức quy mô trong /config (Dynamic workflow size: small dưới 5 agent, medium dưới 10, large dưới 50).

Tắt workflow: tắt trong /config, đặt "disableWorkflows": true, hoặc biến môi trường CLAUDE_CODE_DISABLE_WORKFLOWS=1.

# Dynamic Workflows

Dynamic workflow là một **script JavaScript điều phối nhiều subagent cùng lúc**. Claude viết script cho việc bạn mô tả, một runtime chạy nó dưới nền trong khi phiên của bạn vẫn dùng được. Script lưu trong `.claude/workflows/` trở thành một lệnh `/<tên>` để chạy lại về sau.

Dùng workflow khi việc cần nhiều agent hơn một cuộc hội thoại điều phối nổi, hoặc khi bạn muốn quy trình điều phối được ghi thành script để đọc và chạy lại: quét bug toàn codebase, migrate 500 file, nghiên cứu cần đối chiếu nhiều nguồn.

## Bắt đầu nhanh

1. Thử workflow có sẵn: `/deep-research <câu hỏi>`
2. Hoặc thêm từ khoá `ultracode` vào prompt (hay nói "dùng workflow") để Claude viết workflow cho việc của bạn
3. Duyệt kế hoạch khi được hỏi, rồi theo dõi bằng `/workflows`
4. Chạy ổn thì mở `/workflows`, chọn lượt chạy, nhấn `s` để lưu thành lệnh

```text
ultracode: kiểm tra mọi API endpoint trong src/routes/ xem có thiếu kiểm tra xác thực không
```

Có trên mọi gói trả phí, Anthropic API, Amazon Bedrock, Google Cloud và Microsoft Foundry. Với gói Pro, bật ở dòng Dynamic workflows trong `/config`.

## Workflow khác gì các cách khác

|---|---|---|---|---|
| Là gì | Worker Claude sinh ra | Chỉ dẫn Claude làm theo | Agent trưởng giám sát các phiên ngang hàng | Script do runtime chạy |
| Ai quyết định bước tiếp | Claude, từng lượt | Claude, theo prompt | Agent trưởng, từng lượt | Script |
| Kết quả trung gian nằm ở | Context window của Claude | Context window của Claude | Danh sách việc chung | Biến trong script |
| Lặp lại được gì | Định nghĩa worker | Chỉ dẫn | Định nghĩa team | Chính quy trình điều phối |
| Quy mô | Vài việc mỗi lượt | Như subagent | Vài phiên chạy lâu | Hàng chục tới hàng trăm agent mỗi lượt chạy |

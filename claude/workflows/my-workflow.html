Khung mẫu Workflow

Một workflow đã lưu: khối meta, agent(), pipeline(), phase() và cách nhận args.

File liên quan
.claude/workflows/WORKFLOWS.md
.claude/workflows/my-workflow.js
js
// .claude/workflows/my-workflow.js
//
// Một dynamic workflow đã lưu. File này chạy được bằng lệnh /audit-routes
// trong mọi phiên mở dự án này.
//
// Thường bạn không tự viết file này: Claude viết khi bạn yêu cầu
// "dùng workflow để…", và bạn lưu lại bằng phím `s` trong /workflows.
// Muốn sửa, chạy skill /workflow-authoring trước để Claude nạp tài liệu
// viết script, rồi chạy /reload-skills để nhận bản mới.

// ── meta: bắt buộc là câu lệnh đầu tiên ─────────────────────────
// Phải là object literal thuần (không biến, không gọi hàm, không spread),
// nếu không lệnh /audit-routes sẽ không hiện trong menu `/`.
export const meta = {
  name: 'audit-routes',
  description: 'Kiểm tra mọi route handler xem có thiếu xác thực không',
  phases: ['Tìm file', 'Kiểm tra', 'Xác minh'],
}

// ── Đầu vào ─────────────────────────────────────────────────────
// `args` là dữ liệu truyền khi gọi lệnh, ví dụ:
//   "Chạy /audit-routes cho thư mục src/admin/"
// Không truyền gì thì args là undefined.
const root = args?.dir ?? 'src/routes/'

// ── Phase 1: một agent liệt kê file ─────────────────────────────
// `schema` buộc agent trả JSON đúng khuôn thay vì văn xuôi.
phase('Tìm file')
const found = await agent(`Liệt kê mọi file .ts trong ${root}.`, {
  schema: {
    type: 'object',
    required: ['files'],
    properties: { files: { type: 'array', items: { type: 'string' } } },
  },
})
log(`Tìm thấy ${found.files.length} file`)

// ── Phase 2: mỗi file một agent, chạy song song ─────────────────
// pipeline() sinh một agent cho mỗi phần tử. Agent bị dừng hoặc lỗi
// trả về null, nên lọc bằng .filter(Boolean).
phase('Kiểm tra')
const audits = (await pipeline(found.files, file =>
  agent(`Kiểm tra ${file}: route nào thiếu kiểm tra xác thực? Trả lời "OK" nếu không có.`, {
    label: file,
  }),
)).filter(Boolean)

// ── Phase 3: phản biện trước khi báo cáo ────────────────────────
// Một agent độc lập kiểm tra lại từng phát hiện để lọc báo động giả.
phase('Xác minh')
const issues = audits.filter(a => !String(a).trim().startsWith('OK'))
const verified = await pipeline(issues, finding =>
  agent(`Kiểm chứng phát hiện sau bằng cách đọc code thật. Chỉ giữ nếu đúng:\n${finding}`),
)

// Giá trị return là thứ Claude nhận lại và báo cho bạn.
return verified.filter(Boolean)

// ── Quy tắc cần nhớ ─────────────────────────────────────────────
//   agent()     sinh một subagent, trả về kết quả của nó
//   pipeline()  một agent cho mỗi phần tử trong danh sách
//   parallel()  chạy một nhóm tác vụ cùng lúc và chờ tất cả
//   phase()     nhóm các agent tiếp theo dưới một tiêu đề trong /workflows
//   log()       hiện một dòng thông báo phía trên các phase
//
// Date.now(), Math.random() và new Date() không tham số sẽ báo lỗi trong
// script, để lượt chạy lại cho kết quả giống hệt. Cần thời gian thì
// truyền qua `args`.

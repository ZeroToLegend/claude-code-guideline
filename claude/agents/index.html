Agents

Agent là các phiên bản Claude cô lập mà bạn tạo và cấu hình cho tác vụ chuyên biệt. Có hai dạng: subagentWorker tập trung chạy trong phiên của bạn, làm một việc rồi trả về bản tóm tắt hoạt động trong phiên của bạn, và agent teamNhiều phiên Claude Code độc lập phối hợp qua một danh sách việc chung phối hợp giữa các phiên riêng biệt.

Bắt đầu nhanh

  1. Chạy /agents trong Claude Code để mở trình quản lý agent tương tác
  2. Chọn Create new agent, rồi chọn phạm vi (project hoặc user)
  3. Chọn Generate with Claude và mô tả việc agent cần làm
  4. Chọn công cụ agent được truy cập, chọn model, rồi lưu

Agent dùng được ngay. Thử: "Dùng agent my-agent để review module này."

Subagent hoạt động thế nào

Subagent là file .md với frontmatter YAML để cấu hình và phần thân Markdown trở thành system prompt. Mỗi subagent chạy trong context window riêng, chỉ dùng công cụ bạn cho phép, và trả bản tóm tắt về hội thoại chính.

  1. Claude so yêu cầu của bạn với trường description của subagent
  2. Một context window mới được tạo với system prompt của subagent
  3. Subagent làm việc độc lập (đọc file, chạy lệnh...)
  4. Kết quả được tóm tắt lại vào hội thoại chính

Subagent có thể chạy foreground (chặn) hoặc background (song song). Nhấn Ctrl+B để đưa tác vụ đang chạy xuống nền.

Agent nằm ở đâu

Vị trí Phạm vi Ưu tiên
Cờ CLI --agents Chỉ phiên hiện tại 1 (cao nhất)
.claude/agents/ Dự án này (commit vào git) 2
~/.claude/agents/ Mọi dự án của bạn 3
Thư mục agents/ của plugin Nơi plugin được bật 4 (thấp nhất)

Khi nhiều agent trùng tên, vị trí ưu tiên cao hơn thắng.

Subagent có sẵn

Claude Code đi kèm các subagent nó tự dùng:

  • Explore: tìm kiếm codebase nhanh, chỉ đọc (chạy trên Haiku)
  • Plan: lập kế hoạch và phân tích có cấu trúc
  • General-purpose: trợ thủ linh hoạt cho các việc giao phó linh tinh

Bạn có thể tạo agent tuỳ chỉnh ghi đè agent có sẵn bằng cách dùng cùng tên ở phạm vi ưu tiên cao hơn.

Agent Teams

Agent team điều phối nhiều phiên Claude Code độc lập làm việc song song. Một phiên làm trưởng nhóm; các phiên khác là đồng đội với context window riêng.

Agent team đang ở dạng thử nghiệm. Bật trong settings.json:

json
{
  "env": {
    "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1"
  }
}

Rồi mô tả cấu trúc nhóm bằng ngôn ngữ tự nhiên:

Tạo một agent team để review PR #142. Sinh ba reviewer:
một người tập trung bảo mật, một người kiểm tra hiệu năng, một người xác minh test.

Subagents vs Agent Teams

Subagents Agent Teams
Giao tiếp Chỉ báo kết quả về bên gọi Đồng đội nhắn tin trực tiếp cho nhau
Bối cảnh Window riêng; kết quả trả về phiên chính Window riêng; hoàn toàn độc lập
Phối hợp Agent chính quản lý mọi việc Danh sách việc chung, tự phối hợp
Hợp nhất cho Việc tập trung, chỉ cần kết quả Việc phức tạp cần thảo luận
Chi phí token Thấp hơn (kết quả được tóm tắt lại) Cao hơn (mỗi đồng đội là một phiên riêng)

Dùng subagent cho worker nhanh, tập trung. Dùng agent team khi các thành viên cần chia sẻ phát hiện và tự phối hợp.

Khuôn mẫu thường gặp

  • Cô lập output dài dòng: giao việc chạy test hay phân tích log cho subagent để output không chiếm bối cảnh chính
  • Nghiên cứu song song: sinh nhiều subagent điều tra các phần khác nhau của codebase cùng lúc
  • Nối chuỗi subagent: một cái để phân tích, chuyển phát hiện cho cái khác để triển khai
  • Giả thuyết cạnh tranh: sinh thành viên agent team điều tra các giả thuyết khác nhau và tranh luận với nhau

Mẹo

  • Viết trường description chi tiết để Claude biết khi nào giao việc. Thêm "use proactively" cho agent bạn muốn được dùng tự động
  • Chỉ cấp công cụ agent cần. Reviewer chỉ đọc thì không nên có Write hay Edit
  • Subagent không thể sinh subagent khác. Để giao việc lồng nhau, dùng skills hoặc nối chuỗi từ hội thoại chính
  • Dùng memory: project (hoặc user) để agent tích luỹ kiến thức qua các phiên, lưu trong agent-memory/Thư mục bộ nhớ lâu dài của từng subagent. Xem .claude/agent-memory. Bảo chúng "kiểm tra bộ nhớ" trước khi bắt đầu và "lưu điều đã học" sau khi xong
  • Agent team hiệu quả nhất với 3-5 thành viên và 5-6 việc mỗi người. Càng nhiều thành viên càng tốn công điều phối
  • Đồng đội nạp CLAUDE.md từ thư mục làm việc, nên quy ước dự án áp dụng cho cả nhóm

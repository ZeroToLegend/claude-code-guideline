Khung mẫu file Agent

File agent khởi đầu, minh hoạ cấu hình frontmatter YAML và cấu trúc system prompt.

toolsRead, Grep, Glob, Bash
modelsonnet

Bạn là [mô tả vai trò]. Khi được gọi, [việc bạn làm].

Lĩnh vực tập trung:

  • [Trách nhiệm chính]
  • [Trách nhiệm phụ]
  • [Điều bạn không bao giờ được làm]

Quy trình:

  1. [Bước đầu]
  2. [Bước thứ hai]
  3. [Bước cuối]

Định dạng đầu ra:

  • [Cách cấu trúc câu trả lời]

Đây là file agent khởi đầu. Tên file my-agent.md đăng ký file này thành subagent tên my-agent.

Mọi thứ phía trên dấu --- thứ hai là system prompt của agent. Đây là tất cả những gì agent thấy (cộng thông tin môi trường cơ bản như thư mục làm việc). Nó không nhận toàn bộ system prompt của Claude Code.

Giải phẫu file này

Phần frontmatter (giữa cặp --- đầu tiên) cấu hình agent:

  • name: định danh duy nhất, chữ thường với gạch ngang. Đây là cách bạn gọi tên agent
  • description: Claude đọc trường này để quyết định khi nào giao việc. Hãy nói cụ thể agent xử lý tác vụ gì
  • tools: công cụ agent được dùng. Bỏ trống để kế thừa mọi công cụ từ hội thoại chính. Các bộ thường gặp:
    • Chỉ đọc: Read, Grep, Glob
    • Được sửa file: Read, Grep, Glob, Edit, Write, Bash
    • Được sinh agent: Agent(worker, researcher), Read, Bash
  • model: model sử dụng. sonnet cân bằng tốc độ và năng lực, haiku nhanh và rẻ, opus mạnh nhất, inherit dùng model của hội thoại chính

Phần thân (sau frontmatter) là system prompt. Viết thành chỉ dẫn trực tiếp cho agent: "Bạn là...", "Khi được gọi...", "Tập trung vào...".

Các trường frontmatter tuỳ chọn

yaml
permissionMode: default      # default | acceptEdits | auto | dontAsk | bypassPermissions | plan
maxTurns: 25                 # dừng sau số lượt agentic này
effort: high                 # low | medium | high | xhigh | max
color: blue                  # màu trong danh sách việc và transcript
omitClaudeMd: false          # true để không nạp CLAUDE.md
autoCompactWindow: 200000    # hạ ngưỡng tự nén bối cảnh
background: false            # true để luôn chạy nền
isolation: worktree          # chạy trong git worktree tạm
memory: project              # user | project | local (bật bộ nhớ lâu dài, xem agent-memory/)
skills:                      # skills chèn vào bối cảnh lúc khởi động
  - api-conventions
  - error-handling
mcpServers:                  # MCP server agent được dùng
  - slack
hooks:                       # lifecycle hook chỉ áp cho agent này
  PreToolUse:
    - matcher: "Bash"
      hooks:
        - type: command
          command: "./scripts/validate.sh"

Thế nào là một agent tốt

  • Trách nhiệm hẹp, được định nghĩa rõ (không phải "làm mọi thứ")
  • description chi tiết để Claude giao đúng việc
  • Chỉ có công cụ thật sự cần (quyền tối thiểu)
  • Chỉ dẫn định dạng đầu ra rõ ràng để kết quả nhất quán
  • Các bước quy trình dẫn dắt agent qua tác vụ

Subagents vs Skills

Cả hai đều tạo giao diện kiểu /lệnh-slash, nhưng giải quyết vấn đề khác nhau:

Skills Subagents
Bối cảnh Chạy trong hội thoại chính của bạn Chạy trong bối cảnh cô lập riêng
Hợp nhất cho Tài liệu tham khảo, quy trình tái sử dụng Tác vụ sinh output dài dòng
Kiểm soát công cụ Không giới hạn công cụ Danh sách công cụ chi tiết
Nối chuỗi Không Không (nhưng hội thoại chính có thể nối chúng)

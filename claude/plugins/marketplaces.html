Plugin Marketplaces

Marketplace là một danh mục liệt kê plugin và chỉ cho Claude Code nơi tải chúng. Nó cung cấp khả năng khám phá tập trung, theo dõi phiên bản và cập nhật tự động. Bạn có thể tạo marketplace cho nhóm, cho cộng đồng, hoặc công khai.

Bắt đầu nhanh

  1. Tạo một thư mục có .claude-plugin/marketplace.json
  2. Liệt kê các plugin kèm tên, nguồn và mô tả
  3. Đẩy lên GitHub (hoặc git host bất kỳ)
  4. Người dùng thêm marketplace: /plugin marketplace add owner/repo
  5. Người dùng cài plugin: /plugin install my-plugin@your-marketplace

Cách hoạt động

  1. Bạn tạo plugin với skills, agents, hooks, MCP server hoặc LSP server
  2. Bạn tạo marketplace.json liệt kê các plugin đó và nơi tìm chúng
  3. Bạn host nó trên GitHub, GitLab hoặc git host bất kỳ
  4. Người dùng thêm marketplace và cài từng plugin
  5. Người dùng nhận cập nhật bằng cách chạy /plugin marketplace update

Schema của marketplace

File marketplace.json nằm ở .claude-plugin/marketplace.json trong thư mục gốc repository.

Trường bắt buộc

Trường Kiểu Mục đích
name string Định danh marketplace (kebab-case). Người dùng thấy nó khi cài: /plugin install tool@your-marketplace
owner object Thông tin người duy trì: name (bắt buộc), email (tuỳ chọn)
plugins array Danh sách plugin có sẵn

Metadata tuỳ chọn

Trường Mục đích
metadata.description Mô tả ngắn về marketplace
metadata.version Phiên bản marketplace
metadata.pluginRoot Thư mục gốc được ghép vào trước đường dẫn nguồn tương đối của plugin

Nguồn plugin

Mỗi mục plugin cần name và source. Source cho Claude Code biết nơi tải plugin:

Nguồn Định dạng Ghi chú
Đường dẫn tương đối "./plugins/my-plugin" Trong repo marketplace. Phải bắt đầu bằng ./
GitHub { "source": "github", "repo": "owner/repo" } Hỗ trợ ghim ref (nhánh/tag) và sha (commit)
Git URL { "source": "url", "url": "https://...git" } Git host bất kỳ. URL phải kết thúc bằng .git
Git subdirectory { "source": "git-subdir", "url": "...", "path": "..." } Sparse clone một thư mục con trong monorepo
npm { "source": "npm", "package": "@org/plugin" } Hỗ trợ dải version và registry tuỳ chỉnh
pip { "source": "pip", "package": "plugin" } Cài qua pip

Ghim phiên bản

Nguồn GitHub và git hỗ trợ ref (nhánh hoặc tag) và sha (commit chính xác):

json
{
  "name": "my-plugin",
  "source": {
    "source": "github",
    "repo": "company/my-plugin",
    "ref": "v2.0.0",
    "sha": "a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0"
  }
}

Hosting

GitHub (Khuyên dùng)

Tạo repo, thêm .claude-plugin/marketplace.json, và chia sẻ. Người dùng thêm bằng:

/plugin marketplace add owner/repo

Repository riêng tư

Claude Code dùng thông tin đăng nhập git sẵn có của bạn. Nếu git clone chạy được trong terminal, nó chạy được trong Claude Code. Để tự động cập nhật dưới nền, đặt token trong môi trường:

Nhà cung cấp Biến môi trường
GitHub GITHUB_TOKEN hoặc GH_TOKEN
GitLab GITLAB_TOKEN hoặc GL_TOKEN
Bitbucket BITBUCKET_TOKEN

Phân phối cho nhóm

Cấu hình repo để thành viên nhóm tự động được nhắc cài marketplace của bạn. Thêm vào .claude/settings.json:

json
{
  "extraKnownMarketplaces": {
    "company-tools": {
      "source": {
        "source": "github",
        "repo": "your-org/claude-plugins"
      }
    }
  },
  "enabledPlugins": {
    "code-formatter@company-tools": true
  }
}

Giới hạn do quản trị

Quản trị viên có thể giới hạn marketplace người dùng được thêm bằng strictKnownMarketplaces trong managed settingsCài đặt cấp tổ chức do IT/DevOps kiểm soát, người dùng cá nhân không ghi đè được:

Giá trị Hành vi
Không đặt (mặc định) Không giới hạn. Người dùng thêm được mọi marketplace
Mảng rỗng [] Khoá hoàn toàn. Không cho thêm marketplace mới
Danh sách nguồn Người dùng chỉ thêm được marketplace khớp danh sách cho phép

Strict Mode

Trường strict trên mục plugin quyết định ai định nghĩa các thành phần của plugin:

Giá trị Hành vi
true (mặc định) plugin.json là nguồn chuẩn. Mục marketplace có thể bổ sung thêm thành phần
false Mục marketplace là toàn bộ định nghĩa. Nếu plugin cũng có plugin.json khai báo thành phần, nó sẽ không nạp được

Dùng strict: false khi người vận hành marketplace muốn toàn quyền quyết định thành phần nào được công bố.

Kênh phát hành

Thiết lập kênh "stable" và "latest" bằng cách tạo hai marketplace trỏ tới hai ref khác nhau của cùng một repo. Gán chúng cho các nhóm người dùng khác nhau qua managed settings.

plugin.json của plugin phải khai báo version khác nhau ở mỗi ref được ghim. Nếu hai ref cùng phiên bản, Claude Code sẽ bỏ qua cập nhật.

Kiểm tra

Kiểm tra marketplace trước khi chia sẻ:

bash
claude plugin validate .

Hoặc từ trong Claude Code:

/plugin validate .
/plugin marketplace add ./my-local-marketplace
/plugin install test-plugin@my-local-marketplace

Tên dành riêng

Các tên marketplace sau được dành riêng cho Anthropic: claude-code-marketplace, claude-code-plugins, claude-plugins-official, anthropic-marketplace, anthropic-plugins, agent-skills, life-sciences. Tên giả mạo marketplace chính thức cũng bị chặn.

Mẹo

  • Đường dẫn tương đối chỉ hoạt động khi người dùng thêm marketplace qua git (không phải qua URL trực tiếp tới marketplace.json)

  • Đặt CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS để tăng timeout git 120 giây cho repo lớn

Marketplace là một danh mục liệt kê plugin và chỉ cho Claude Code nơi tải chúng. Nó cung cấp khả năng khám phá tập trung, theo dõi phiên bản và cập nhật tự động. Bạn có thể tạo marketplace cho nhóm, cho cộng đồng, hoặc công khai.

## Bắt đầu nhanh

1. Tạo một thư mục có `.claude-plugin/marketplace.json`
2. Liệt kê các plugin kèm tên, nguồn và mô tả
3. Đẩy lên GitHub (hoặc git host bất kỳ)
4. Người dùng thêm marketplace: `/plugin marketplace add owner/repo`
5. Người dùng cài plugin: `/plugin install my-plugin@your-marketplace`

## Cách hoạt động

1. **Bạn tạo plugin** với skills, agents, hooks, MCP server hoặc LSP server
2. **Bạn tạo `marketplace.json`** liệt kê các plugin đó và nơi tìm chúng
3. **Bạn host nó** trên GitHub, GitLab hoặc git host bất kỳ
4. **Người dùng thêm marketplace** và cài từng plugin
5. **Người dùng nhận cập nhật** bằng cách chạy `/plugin marketplace update`

## Schema của marketplace

File `marketplace.json` nằm ở `.claude-plugin/marketplace.json` trong thư mục gốc repository.

### Trường bắt buộc

| Trường | Kiểu | Mục đích |
|---|---|---|
| `name` | string | Định danh marketplace (kebab-case). Người dùng thấy nó khi cài: `/plugin install tool@your-marketplace` |
| `owner` | object | Thông tin người duy trì: `name` (bắt buộc), `email` (tuỳ chọn) |
| `plugins` | array | Danh sách plugin có sẵn |

### Metadata tuỳ chọn

| Trường | Mục đích |
|---|---|
| `metadata.description` | Mô tả ngắn về marketplace |
| `metadata.version` | Phiên bản marketplace |
| `metadata.pluginRoot` | Thư mục gốc được ghép vào trước đường dẫn nguồn tương đối của plugin |

## Nguồn plugin

Mỗi mục plugin cần `name` và `source`. Source cho Claude Code biết nơi tải plugin:

| Nguồn | Định dạng | Ghi chú |
|---|---|---|
| Đường dẫn tương đối | `"./plugins/my-plugin"` | Trong repo marketplace. Phải bắt đầu bằng `./` |

| Git URL | `{ "source": "url", "url": "https://...git" }` | Git host bất kỳ. URL phải kết thúc bằng `.git` |
| Git subdirectory | `{ "source": "git-subdir", "url": "...", "path": "..." }` | Sparse clone một thư mục con trong monorepo |
| npm | `{ "source": "npm", "package": "@org/plugin" }` | Hỗ trợ dải `version` và `registry` tuỳ chỉnh |
| pip | `{ "source": "pip", "package": "plugin" }` | Cài qua pip |

Nguồn GitHub và git hỗ trợ `ref` (nhánh hoặc tag) và `sha` (commit chính xác):

Plugins

Plugin đóng gói skills, agents, hooks và MCP server thành tiện ích chia sẻ được. Một plugin là thư mục có manifest .claude-plugin/plugin.json và một hoặc nhiều thành phần ở cấp gốc.

Bắt đầu nhanh

  1. Tạo thư mục cho plugin: mkdir my-plugin
  2. Thêm manifest: my-plugin/.claude-plugin/plugin.json
  3. Thêm thành phần (skills, agents, hooks, MCP server) ở gốc plugin
  4. Thử cục bộ: claude --plugin-dir ./my-plugin

Khi nào dùng plugin

Cách làm Tên skill Hợp nhất cho
Standalone (thư mục .claude/) /hello Quy trình cá nhân, tuỳ biến riêng dự án, thử nghiệm nhanh
Plugin (.claude-plugin/plugin.json) /plugin-name:hello Chia sẻ cho đồng đội, phân phối cộng đồng, phát hành có phiên bản

Bắt đầu với cấu hình standalone để lặp nhanh, rồi chuyển sang plugin khi bạn sẵn sàng chia sẻ.

Cấu trúc plugin

my-plugin/
  .claude-plugin/
    plugin.json          # Manifest (bắt buộc)
  skills/                # Agent Skills với file SKILL.md
  commands/              # Skills dạng file Markdown
  agents/                # Định nghĩa agent tuỳ chỉnh
  hooks/                 # Event handler trong hooks.json
  .mcp.json              # Cấu hình MCP server
  .lsp.json              # Cấu hình LSP server
  settings.json          # Cài đặt mặc định khi plugin được bật

Chỉ plugin.json nằm trong .claude-plugin/. Mọi thư mục khác nằm ở gốc plugin.

Mods

Plugin cũng có thể mang modHook JavaScript hoặc TypeScript chạy bên trong phiên và có thể vẽ UI tuỳ chỉnh. Xem mục mods: hooks/hooks.json liệt kê module JavaScript thay vì lệnh shell. Xem .claude/mods/ để biết cấu trúc đầy đủ.

Manifest của plugin

File plugin.json định nghĩa danh tính của plugin:

json
{
  "name": "my-plugin",
  "description": "Plugin này làm gì",
  "version": "1.0.0",
  "author": {
    "name": "Tên của bạn"
  }
}
Trường Mục đích
name Định danh duy nhất và namespace của skill. Skill được thêm tiền tố này (vd. /my-plugin:hello)
description Hiện trong trình quản lý plugin khi duyệt hoặc cài đặt
version Theo dõi bản phát hành bằng semantic versioningĐịnh dạng major.minor.patch như 1.2.3. Major = thay đổi phá vỡ tương thích, minor = tính năng mới, patch = sửa lỗi
author Tuỳ chọn. Hữu ích để ghi công

Các trường tuỳ chọn khác: homepage, repository, license, keywords.

Namespace

Skill của plugin luôn có namespace để tránh xung đột. Skill tên review trong plugin code-tools trở thành /code-tools:review. Để đổi tiền tố namespace, sửa trường name trong plugin.json.

Thêm thành phần

Skills

Thêm thư mục skills/ chứa các thư mục skill có file SKILL.md. Mỗi skill cần frontmatter với name và description:

yaml
---
name: code-review
description: Review code theo thực hành tốt và tìm vấn đề tiềm ẩn
---

Khi review code, kiểm tra:
1. Cách tổ chức và cấu trúc code
2. Xử lý lỗi
3. Vấn đề bảo mật

LSP Servers

Thêm file .lsp.json để Claude có trí tuệ mã nguồn thời gian thực cho ngôn ngữ chưa được plugin chính thức hỗ trợ:

json
{
  "go": {
    "command": "gopls",
    "args": ["serve"],
    "extensionToLanguage": { ".go": "go" }
  }
}

Cài đặt mặc định

Thêm settings.json để áp cấu hình khi plugin được bật. Hiện hỗ trợ khoá agent để kích hoạt một agent tuỳ chỉnh làm luồng chính:

json
{
  "agent": "security-reviewer"
}

Thử cục bộ

Dùng cờ --plugin-dir khi phát triển:

bash
claude --plugin-dir ./my-plugin

Nạp nhiều plugin cùng lúc:

bash
claude --plugin-dir ./plugin-one --plugin-dir ./plugin-two

Thử từng thành phần: chạy skill bằng /plugin-name:skill-name, kiểm tra agent bằng /agents, xác nhận hook kích hoạt đúng.

Chuyển từ standalone

Nếu bạn đã có skills hay hooks trong .claude/, chuyển chúng thành plugin:

  1. Tạo thư mục plugin với .claude-plugin/plugin.json
  2. Sao chép các thư mục commands/, agents/, skills/ sẵn có
  3. Chuyển hooks từ settings.json sang hooks/hooks.json
  4. Thử bằng --plugin-dir
Standalone (.claude/) Plugin
Chỉ dùng được trong một dự án Chia sẻ qua marketplace
File trong .claude/commands/ File trong plugin-name/commands/
Hooks trong settings.json Hooks trong hooks/hooks.json
Phải tự sao chép để chia sẻ Cài bằng /plugin install

Chia sẻ plugin

Khi plugin đã sẵn sàng:

  1. Thêm README.md hướng dẫn cài đặt và sử dụng
  2. Đánh phiên bản plugin theo semantic versioning
  3. Phân phối qua một marketplaceDanh mục liệt kê plugin và nơi tải chúng. Xem MARKETPLACES.md hoặc chia sẻ trực tiếp repository
  4. Gửi lên marketplace chính thức của Anthropic qua claude.ai/settings/plugins/submit

Mẹo

  • Dùng claude plugin validate . hoặc /plugin validate . để kiểm tra lỗi plugin
  • Dùng ${CLAUDE_PLUGIN_ROOT} trong lệnh hook và cấu hình MCP để tham chiếu file trong thư mục cài đặt của plugin
  • Plugin được sao chép vào cache khi cài. File nằm ngoài thư mục plugin sẽ không dùng được - dùng symlink nếu cần
  • Khởi động lại Claude Code sau khi sửa để nhận cập nhật
  • Giữ skills dưới 500 dòng. Chuyển tài liệu chi tiết sang thư mục con references/ hoặc assets/

# Plugins

Plugin đóng gói skills, agents, hooks và MCP server thành tiện ích chia sẻ được. Một plugin là thư mục có manifest `.claude-plugin/plugin.json` và một hoặc nhiều thành phần ở cấp gốc.

## Bắt đầu nhanh

1. Tạo thư mục cho plugin: `mkdir my-plugin`
2. Thêm manifest: `my-plugin/.claude-plugin/plugin.json`
3. Thêm thành phần (skills, agents, hooks, MCP server) ở gốc plugin
4. Thử cục bộ: `claude --plugin-dir ./my-plugin`

## Khi nào dùng plugin

| Cách làm | Tên skill | Hợp nhất cho |
|---|---|---|
| **Standalone** (thư mục `.claude/`) | `/hello` | Quy trình cá nhân, tuỳ biến riêng dự án, thử nghiệm nhanh |
| **Plugin** (`.claude-plugin/plugin.json`) | `/plugin-name:hello` | Chia sẻ cho đồng đội, phân phối cộng đồng, phát hành có phiên bản |

Bắt đầu với cấu hình standalone để lặp nhanh, rồi chuyển sang plugin khi bạn sẵn sàng chia sẻ.

## Cấu trúc plugin

```
my-plugin/
  .claude-plugin/
    plugin.json          # Manifest (bắt buộc)
  skills/                # Agent Skills với file SKILL.md
  commands/              # Skills dạng file Markdown
  agents/                # Định nghĩa agent tuỳ chỉnh
  hooks/                 # Event handler trong hooks.json
  .mcp.json              # Cấu hình MCP server
  .lsp.json              # Cấu hình LSP server
  settings.json          # Cài đặt mặc định khi plugin được bật
```

Chỉ `plugin.json` nằm trong `.claude-plugin/`. Mọi thư mục khác nằm ở gốc plugin.

## Manifest của plugin


|---|---|

## Chuyển từ standalone

Nếu bạn đã có skills hay hooks trong `.claude/`, chuyển chúng thành plugin:

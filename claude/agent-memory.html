agent-memory/

Bộ nhớ lâu dài riêng cho từng subagent. Khi một subagentPhiên bản Claude cô lập với prompt và công cụ riêng. Xem .claude/agents có trường memory trong frontmatter, nó có một thư mục để ghi lại điều đã học, như khuôn mẫu codebase, kinh nghiệm debug, quyết định kiến trúc, và đọc lại ở các lần chạy sau.

Bắt đầu nhanh

Thêm memory vào frontmatter của agent:

yaml
---
name: code-reviewer
description: Review code về chất lượng và thực hành tốt
memory: project
---

Bạn là một code reviewer. Trong lúc review, hãy cập nhật agent memory với
các khuôn mẫu, quy ước và lỗi lặp lại mà bạn phát hiện.

Lần chạy đầu, Claude Code tạo thư mục .claude/agent-memory/code-reviewer/.

Ba phạm vi

Phạm vi Vị trí Dùng khi
user ~/.claude/agent-memory/<tên-agent>/ Agent cần nhớ bài học trên mọi dự án
project .claude/agent-memory/<tên-agent>/ Kiến thức riêng của dự án, chia sẻ qua git
local .claude/agent-memory-local/<tên-agent>/ Kiến thức riêng của dự án nhưng không nên commit

project là phạm vi nên dùng mặc định: kiến thức của agent được commit, cả nhóm cùng hưởng.

Bên trong thư mục

.claude/agent-memory/code-reviewer/
├── MEMORY.md            # Mục lục, nạp mỗi lần agent chạy
└── auth-patterns.md     # File chủ đề, agent đọc khi cần

Khi bật memory:

  • System prompt của agent có thêm hướng dẫn đọc và ghi vào thư mục bộ nhớ
  • 200 dòng hoặc 25KB đầu tiên của MEMORY.md được nạp vào system prompt, kèm lời dặn tự gọn lại nếu vượt giới hạn
  • Công cụ Read, Write và Edit được bật tự động để agent quản lý file bộ nhớ

Quan hệ với auto memory

Bộ nhớ của subagent là một phần của auto memoryGhi chú Claude tự viết cho mình qua các phiên. Xem built-in/auto-memory. Nếu bạn tắt auto memory (cài đặt autoMemoryEnabled hoặc biến CLAUDE_CODE_DISABLE_AUTO_MEMORY), trường memory không còn tác dụng.

Auto memory Agent memory
Của ai Hội thoại chính Từng subagent
Vị trí ~/.claude/projects/<project>/memory/ agent-memory/<tên-agent>/ theo phạm vi
Commit được Không, chỉ trên máy Có, với phạm vi project

Mẹo

  • Bảo agent tra bộ nhớ trước khi làm: "Review PR này, và kiểm tra bộ nhớ xem có khuôn mẫu nào đã gặp"
  • Bảo agent lưu lại sau khi xong: "Xong rồi, lưu điều bạn học được vào bộ nhớ"
  • Viết sẵn chỉ dẫn duy trì bộ nhớ trong file agent để nó tự làm mà không cần nhắc
  • Đây là dữ liệu trạng thái cần giữ. Đừng xoá agent-memory/ khi dọn dẹp ~/.claude

# agent-memory/

Bộ nhớ lâu dài **riêng cho từng subagent**. Khi một [subagent](^Phiên bản Claude cô lập với prompt và công cụ riêng. Xem .claude/agents) có trường `memory` trong frontmatter, nó có một thư mục để ghi lại điều đã học, như khuôn mẫu codebase, kinh nghiệm debug, quyết định kiến trúc, và đọc lại ở các lần chạy sau.

## Bắt đầu nhanh

Thêm `memory` vào frontmatter của agent:

```yaml
---
name: code-reviewer
description: Review code về chất lượng và thực hành tốt
memory: project
---

Bạn là một code reviewer. Trong lúc review, hãy cập nhật agent memory với
các khuôn mẫu, quy ước và lỗi lặp lại mà bạn phát hiện.
```

Lần chạy đầu, Claude Code tạo thư mục `.claude/agent-memory/code-reviewer/`.

## Ba phạm vi

| Phạm vi | Vị trí | Dùng khi |
|---|---|---|
| `user` | `~/.claude/agent-memory/<tên-agent>/` | Agent cần nhớ bài học trên mọi dự án |
| `project` | `.claude/agent-memory/<tên-agent>/` | Kiến thức riêng của dự án, chia sẻ qua git |
| `local` | `.claude/agent-memory-local/<tên-agent>/` | Kiến thức riêng của dự án nhưng không nên commit |

`project` là phạm vi nên dùng mặc định: kiến thức của agent được commit, cả nhóm cùng hưởng.

## Bên trong thư mục

```
.claude/agent-memory/code-reviewer/
├── MEMORY.md            # Mục lục, nạp mỗi lần agent chạy
└── auth-patterns.md     # File chủ đề, agent đọc khi cần
```

Khi bật memory:

- System prompt của agent có thêm hướng dẫn đọc và ghi vào thư mục bộ nhớ
- **200 dòng hoặc 25KB đầu tiên** của `MEMORY.md` được nạp vào system prompt, kèm lời dặn tự gọn lại nếu vượt giới hạn
- Công cụ Read, Write và Edit được bật tự động để agent quản lý file bộ nhớ

## Quan hệ với auto memory

Bộ nhớ của subagent là một phần của [auto memory](^Ghi chú Claude tự viết cho mình qua các phiên. Xem built-in/auto-memory). Nếu bạn tắt auto memory (cài đặt `autoMemoryEnabled` hoặc biến `CLAUDE_CODE_DISABLE_AUTO_MEMORY`), trường `memory` không còn tác dụng.

| | Auto memory | Agent memory |
|---|---|---|
| Của ai | Hội thoại chính | Từng subagent |
| Vị trí | `~/.claude/projects/<project>/memory/` | `agent-memory/<tên-agent>/` theo phạm vi |
| Commit được | Không, chỉ trên máy | Có, với phạm vi `project` |

## Mẹo

- Bảo agent tra bộ nhớ trước khi làm: "Review PR này, và kiểm tra bộ nhớ xem có khuôn mẫu nào đã gặp"
- Bảo agent lưu lại sau khi xong: "Xong rồi, lưu điều bạn học được vào bộ nhớ"
- Viết sẵn chỉ dẫn duy trì bộ nhớ trong file agent để nó tự làm mà không cần nhắc
- Đây là dữ liệu trạng thái cần giữ. Đừng xoá `agent-memory/` khi dọn dẹp `~/.claude`

Skills

Gói hướng dẫn, tài liệu tham khảo và script có thể tái sử dụng, được Claude phát hiện và nạp khi cầnLúc khởi động Claude chỉ đọc tên và mô tả của skill. Toàn bộ nội dung chỉ được nạp khi skill liên quan tới tác vụ hiện tại. Một skill là một thư mục chứa file SKILL.md. Đó là yêu cầu duy nhất.

Bắt đầu nhanh

  1. Tạo thư mục: .claude/skills/my-skill/
  2. Thêm SKILL.md với frontmatterKhối YAML ở đầu file nằm giữa hai dấu ---. Chứa metadata như name và description gồm name và description
  3. Viết hướng dẫn vào phần thân. Claude đọc chúng khi skill được kích hoạt
  4. Gọi bằng /my-skill hoặc để Claude tự nạp khi phù hợp

Skills tuân theo chuẩn mở Agent Skills, nên chúng chạy được trên nhiều công cụ AI, không chỉ Claude Code.

Cách hoạt động

Skills dùng cơ chế tiết lộ dần (progressive disclosure)Một khuôn mẫu quản lý bối cảnh hiệu quả: nạp một ít lúc đầu, nạp thêm chỉ khi cần. Giúp Claude tập trung và giảm dùng token để luôn hiệu quả:

  1. Khám phá: Lúc khởi động, Claude chỉ nạp name và description của mỗi skill. Vừa đủ để biết khi nào nó có thể liên quan
  2. Kích hoạt: Khi tác vụ khớp, Claude đọc toàn bộ SKILL.md vào bối cảnh
  3. Thực thi: Claude làm theo hướng dẫn, có thể nạp thêm file được tham chiếu hoặc chạy script đi kèm

# Skills

Gói hướng dẫn, tài liệu tham khảo và script có thể tái sử dụng, được Claude phát hiện và nạp [khi cần](^Lúc khởi động Claude chỉ đọc tên và mô tả của skill. ## Bắt đầu nhanh

1. Tạo thư mục: `.claude/skills/my-skill/`
2. Thêm `SKILL.md` với [frontmatter](^Khối YAML ở đầu file nằm giữa hai dấu ---. Chứa metadata như name và description) gồm name và description
3. Viết hướng dẫn vào phần thân. Claude đọc chúng khi skill được kích hoạt
4. Gọi bằng `/my-skill` hoặc để Claude tự nạp khi phù hợp

Skills tuân theo [chuẩn mở Agent Skills](https://agentskills.io), nên chúng chạy được trên nhiều công cụ AI, không chỉ Claude Code.

## Cách hoạt động

Skills dùng cơ chế [tiết lộ dần (progressive disclosure)](^Một khuôn mẫu quản lý bối cảnh hiệu quả: nạp một ít lúc đầu, nạp thêm chỉ khi cần. Giúp Claude tập trung và giảm dùng token) để luôn hiệu quả:

3. **Thực thi**: Claude làm theo hướng dẫn, có thể nạp thêm file được tham chiếu hoặc chạy script đi kèm

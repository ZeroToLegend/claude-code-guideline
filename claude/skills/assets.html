assets/ - Tài nguyên tĩnh

Thư mục này chứa tài nguyên tĩnh mà skill có thể tham chiếu. Là những thứ Claude đọc hoặc điền vào, nhưng không thực thi.

Nên đặt gì ở đây

  • Template: Mẫu tài liệu, mẫu file cấu hình, khung boilerplate mà Claude điền vào mỗi lần dùng
  • Schema: JSON schema, schema cơ sở dữ liệu, cấu trúc phản hồi API
  • File dữ liệu: Bảng tra cứu, file ánh xạ, dữ liệu tham chiếu
  • Hình ảnh: Sơ đồ, ảnh chụp màn hình mẫu (Claude xem được hình ảnh)
  • Đầu ra mẫu: File mẫu cho thấy định dạng mong đợi

Cách hoạt động

SKILL.md tham chiếu asset khi cần:

"Dùng template tại assets/template.md làm điểm khởi đầu."

Claude đọc asset, điền các phần động và tạo ra kết quả. Asset là tĩnh. Chúng không thay đổi giữa các lần gọi.

Ví dụ sử dụng

  • Mẫu PR mà Claude điền vào với các thay đổi thực tế
  • Schema cấu hình mà Claude dùng để kiểm tra
  • Boilerplate component mà Claude tuỳ biến theo từng yêu cầu

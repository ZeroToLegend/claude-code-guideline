Mods là gì?

Cách mod chạy JavaScript trong phiên để quan sát, viết lại hoặc chặn sự kiện và vẽ UI tuỳ chỉnh.

File liên quan
.claude/mods/my-mod/.claude-plugin/plugin.json.claude/mods/my-mod/hooks/hooks.json.claude/mods/my-mod/hooks/my-mod.mjs.claude/mods/my-mod/types/index.d.ts.claude/mods/my-mod/tests/my-mod.test.ts
.claude/mods/MODS.md

Mods

Mod là một file JavaScript hoặc TypeScript nhỏ chạy bên trong phiên Claude Code của bạn. Mod có thể theo dõi việc Claude làm, thay đổi nó trước khi xảy ra, hoặc vẽ UI tuỳ chỉnh trong terminal hay tab Code của desktop app: một dải phía trên ô prompt, một pane gắn cạnh, một status line, hoặc một toast.

Mods cần Claude Code 2.1.287 trở lên, phiên bản mà chúng được bật mặc định.

Bắt đầu nhanh

Cách nhanh nhất để có một mod là mô tả nó:

> tạo một mod hiển thị context window đang đầy bao nhiêu, ngay phía trên ô prompt

Claude Code dùng skill có sẵn /plugin-authoringMột skill tích hợp viết mod dưới dạng plugin nạp nóng. Xem built-in/bundled-skills để viết nó, kể cả phần khai báo kiểu, và nạp thẳng vào phiên của bạn. Để tự viết tay:

  1. Tạo thư mục plugin với .claude-plugin/plugin.json
  2. Thêm hooks/hooks.json liệt kê các file module
  3. Viết module: export hàm register(on)
  4. Nạp nó: claude --plugin-dir ./my-mod

Sửa file và phiên đang chạy sẽ nhận thay đổi. Không cần khởi động lại.

Mods vs. Hooks

Mods nằm cạnh shell hookScript trong settings.json chạy theo từng sự kiện và trao đổi JSON qua stdin/stdout. Xem mục hooks, và khác biệt giữa chúng là quan trọng:

Shell hooks Mods
Viết bằng Ngôn ngữ bất kỳ, chạy như một tiến trình JavaScript hoặc TypeScript
Vòng đời Tiến trình mới cho mỗi sự kiện Nạp một lần, sống suốt phiên
Giao tiếp với Claude Code qua JSON trên stdin/stdout, mã thoát Trực tiếp qua API $
Giữ trạng thái Không (tự ghi ra đĩa) Có, với $.state
Vẽ được UI Không Có: band, pane, status line, toast
Cấu hình trong settings.json hooks/hooks.json của plugin

Dùng shell hook cho cổng kiểm tra hay formatter nhanh. Chọn mod khi bạn cần nhớ giữa các sự kiện, UI sống, hoặc kiểm soát chặt hơn.

Mod hoạt động thế nào

Mỗi module export register(on). Bên trong, bạn gọi on(event, matcher?, hook) để gắn một hook:

javascript
export function register(on) {
  on("tool.call", { tool: "Bash" }, async ($, e, next) => {
    return next(e);
  });
}
Tham số Là gì
$ API của mods: phiên, trạng thái, UI, file, tiến trình, HTTP và nhiều hơn nữa
e Sự kiện: lời gọi công cụ, prompt, component đang được vẽ
next Chuyển sự kiện xuống mắt xích tiếp theo

Hooks tạo thành chuỗi, giống middlewareĐoạn code nằm giữa một request và handler của nó, có thể kiểm tra, sửa đổi hoặc cắt ngang. Hook của bạn chạy, next(e) chuyển sự kiện cho plugin kế tiếp, và ở đáy chuỗi Claude Code làm điều nó vốn sẽ làm. Điều đó cho bạn ba nước đi:

Nước đi Code Tác dụng
Quan sát const r = await next(e); return r Theo dõi mà không thay đổi gì
Viết lại return next({ ...e, command: safer }) Đổi thứ mà mọi mắt xích phía sau nhìn thấy
Trả lời return { deny: "lý do" } Bỏ qua next và tự phản hồi

Các sự kiện hook

Sự kiện Khi nào phát ra
session.start / session.end Phiên bắt đầu hoặc kết thúc
prompt.submit Bạn gửi prompt
turn.start / turn.complete Claude bắt đầu hoặc kết thúc một lượt
tool.call Claude gọi công cụ (khớp bằng { tool: "Bash" })
command.run Một lệnh slash chạy (khớp bằng { command: "name" })
ui.render Một component UI được vẽ (khớp bằng { component: "AbovePrompt" })

API $

Namespace Dùng cho
$.session usage() để lấy số liệu context và token, cwd()
$.state get / set các giá trị có tên, sống sót qua hot reload
$.ui resolve(e) để lấy phần tử UI, open() một pane, status(), toast()
$.command register() lệnh slash của riêng bạn, list() lệnh sẵn có
$.process run(argv) một chương trình, luôn truyền dạng mảng tham số
$.fs, $.http, $.tool, $.clock File, request web, công cụ và bộ hẹn giờ

Mods chạy trong sandboxMôi trường chạy cô lập không có DOM và không có Node.js. Mọi tác động ra ngoài đều đi qua $, nên Claude Code thấy và kiểm soát được. Không có Node.js và không có DOM. Mọi thứ chạm tới thế giới bên ngoài đều đi qua $.

Bề mặt UI

Bề mặt Hiện ở đâu
AbovePrompt Một dải ngay phía trên ô nhập
Pane Bảng gắn bên cạnh, tự thích ứng với độ rộng terminal
Status line Dòng trạng thái ở dưới cùng
Toast Thông báo ngắn hạn

Gọi $.ui.resolve(e) bên trong hook ui.render để lấy các phần tử mà bề mặt đó hỗ trợ, như Box và Text. e.props của sự kiện cho biết không gian bạn có: bodyColumns (độ rộng khả dụng), isWorking (Claude đang bận), và hasSurvey (một khảo sát đã chiếm chỗ này, nên hãy nhường).

Trạng thái và Hot Reload

Trong khi bạn phát triển, thư mục mod được theo dõi và thay đổi được nạp lại vào phiên đang chạy. Biến cấp module sẽ bị reset sau mỗi lần nạp lại. Thứ gì cần tồn tại thì đặt vào $.state:

javascript
const counter = { plugin: "my-mod", key: "blocked" };
const { value: count = 0 } = await $.state.get(counter);
await $.state.set(counter, count + 1);

Đọc state bên trong hook ui.render sẽ đăng ký lần vẽ đó theo dõi nó, nên UI tự vẽ lại mỗi khi giá trị thay đổi. Khai báo mỗi khoá state trong types/index.d.ts để kiểu khớp nhau.

Cấu trúc mod

my-mod/
  .claude-plugin/
    plugin.json          # Manifest, trỏ tới khai báo kiểu
  hooks/
    hooks.json           # Liệt kê các file module cần nạp
    my-mod.mjs           # Bản thân mod
  types/
    index.d.ts           # Khai báo các khoá $.state
  tests/
    my-mod.test.ts       # Test, chạy bằng claude plugin test

Mod là một pluginThư mục có manifest .claude-plugin/plugin.json. Xem mục plugins với function hook, nên nó được phát hành giống như plugin.

Kiểm tra, Test, Chia sẻ

bash
claude plugin validate ./my-mod    # manifest, hợp đồng kiểu, các hook đã khai báo
claude plugin test ./my-mod        # chạy tests/*.test.ts

Để chia sẻ, liệt kê mod trong một marketplaceDanh mục liệt kê plugin và nơi tải chúng. Xem MARKETPLACES.md và đẩy lên GitHub. Người khác cài nó như mọi plugin:

/plugin marketplace add your-org/my-mods
/plugin install my-mod@my-mods
/reload-plugins

Để tiếp cận rộng hơn, gửi nó lên thư mục chính thức tại claude.ai/directory/manage.

Mẹo

  • Mỗi hook có 10 giây thời gian riêng cho mỗi lần gọi. Thời gian chờ bên trong một lời gọi $ không bị tính
  • Truyền tham số tiến trình dạng mảng: $.process.run(["git", "status"]). Không có chuỗi shell nghĩa là không có injection
  • Khi mở pane, kiểm tra opened.isPlaced. Terminal hẹp có thể không đủ chỗ, nên hãy vẽ phương án dự phòng trong band
  • Mod của bạn thấy mọi sự kiện, nhưng mod khác cũng thấy. Bạn có thể trả lời hoặc từ chối sự kiện, nhưng không giấu được nó khỏi phần còn lại của chuỗi
  • Đừng làm việc nặng trong ui.render. Tính toán trong hook sự kiện, lưu kết quả vào $.state, và chỉ đọc nó khi vẽ

Trong khi bạn phát triển, thư mục mod được theo dõi và thay đổi được nạp lại vào phiên đang chạy. Biến cấp module sẽ **bị reset** sau mỗi lần nạp lại. Thứ gì cần tồn tại thì đặt vào `$.state`:

```javascript
const counter = { plugin: "my-mod", key: "blocked" };
const { value: count = 0 } = await $.state.get(counter);
await $.state.set(counter, count + 1);
```

Đọc state bên trong hook `ui.render` sẽ đăng ký lần vẽ đó theo dõi nó, nên UI tự vẽ lại mỗi khi giá trị thay đổi. Khai báo mỗi khoá state trong `types/index.d.ts` để kiểu khớp nhau.

## Cấu trúc mod

```
my-mod/
  .claude-plugin/
    plugin.json          # Manifest, trỏ tới khai báo kiểu
  hooks/
    hooks.json           # Liệt kê các file module cần nạp
    my-mod.mjs           # Bản thân mod
  types/
    index.d.ts           # Khai báo các khoá $.state
  tests/
    my-mod.test.ts       # Test, chạy bằng claude plugin test
```

Mod là một [plugin](^Thư mục có manifest .claude-plugin/plugin.json. Xem mục plugins) với function hook, nên nó được phát hành giống như plugin.

## Kiểm tra, Test, Chia sẻ

```bash
claude plugin validate ./my-mod    # manifest, hợp đồng kiểu, các hook đã khai báo
claude plugin test ./my-mod        # chạy tests/*.test.ts
```

Để chia sẻ, liệt kê mod trong một [marketplace](^Danh mục liệt kê plugin và nơi tải chúng. Xem MARKETPLACES.md) và đẩy lên GitHub. Người khác cài nó như mọi plugin:

```
/plugin marketplace add your-org/my-mods
/plugin install my-mod@my-mods
/reload-plugins
```

Để tiếp cận rộng hơn, gửi nó lên thư mục chính thức tại [claude.ai/directory/manage](https://claude.ai/directory/manage).

## Mẹo

- Mỗi hook có **10 giây thời gian riêng cho mỗi lần gọi**. Thời gian chờ bên trong một lời gọi `$` không bị tính
- Truyền tham số tiến trình dạng mảng: `$.process.run(["git", "status"])`. Không có chuỗi shell nghĩa là không có injection
- Khi mở pane, kiểm tra `opened.isPlaced`. Terminal hẹp có thể không đủ chỗ, nên hãy vẽ phương án dự phòng trong band
- Mod của bạn thấy mọi sự kiện, nhưng mod khác cũng thấy. Bạn có thể trả lời hoặc từ chối sự kiện, nhưng không giấu được nó khỏi phần còn lại của chuỗi
- Đừng làm việc nặng trong `ui.render`. Tính toán trong hook sự kiện, lưu kết quả vào `$.state`, và chỉ đọc nó khi vẽ

settings.local.json

Cài đặt cá nhân của bạn cho một dự án. Claude Code áp file này đè lên .claude/settings.json mà nhóm đã commit, nên bạn đổi được hành vi cho riêng mình mà không ảnh hưởng đồng đội.

Bắt đầu nhanh

Ví dụ nhóm đặt model Sonnet trong .claude/settings.json, còn bạn muốn dùng Opus và cho phép chạy test không cần hỏi:

json
{
  "model": "claude-opus-5-5",
  "permissions": {
    "allow": ["Bash(npm run test *)"]
  },
  "outputStyle": "Concise"
}

Lưu ở .claude/settings.local.json. Chỉ phiên của bạn thay đổi.

Ai tạo file này

Thường thì bạn không cần tự tạo. Claude Code tự ghi vào đây khi:

  • Bạn chọn "Yes, and don't ask again" lúc Claude xin chạy một lệnh Bash. Lựa chọn đó được lưu thành một rule allow
  • Bạn đổi một số tuỳ chọn trong /config, như Show tips, hoặc chọn output style bằng /output-style

Không bị commit

Lần đầu Claude Code ghi file này trong một git repo chưa bỏ qua nó, nó thêm **/.claude/settings.local.json vào file git excludes toàn cục của bạn, nên file không bao giờ lọt vào commit ở bất kỳ repo nào.

Nếu bạn tự tạo bằng tay trước khi Claude Code ghi vào, hãy tự thêm nó vào .gitignore.

Vị trí của nó trong thứ tự ưu tiên

Ưu tiên Nguồn File
1 (cao nhất) Managed managed-settings.json, MDM, cài đặt từ server
2 Dòng lệnh --settings cho một phiên
3 Project local .claude/settings.local.json
4 Shared project .claude/settings.json
5 Người dùng ~/.claude/settings.json

Khoá đơn lẻ (như model) lấy giá trị ở cấp cao nhất có đặt. Danh sách (như permissions.allow) thì được gộp từ mọi file, không file nào xoá mục của file khác.

Vị trí trong git repo

Nếu bạn khởi động Claude Code trong thư mục con của một git repo, file local được đọc và ghi ở gốc repository, nên một lần duyệt có hiệu lực cho cả repo. Trong worktree, Claude Code dùng file ở gốc checkout chính, nên quyền đã duyệt dùng chung cho mọi worktree.

Rule allow không cần bước tin cậy

Vì file thuộc về bạn chứ không thuộc repo, các rule allow trong đó có hiệu lực ngay, không cần bước workspace trustHộp thoại xác nhận bạn tin thư mục này, hiện lần đầu chạy Claude Code trong một thư mục như file đã commit. Nếu file bị git theo dõi, bước tin cậy lại áp dụng.

Mẹo

  • Muốn thử một cài đặt trước khi chia sẻ cho nhóm: đặt vào file local trước, ổn rồi mới chuyển sang .claude/settings.json
  • allow trong file local không vượt được rule ask hay deny từ file dự án hoặc managed
  • Một vài giá trị không có hiệu lực từ file dự án hay local, ví dụ defaultMode: "auto" và "bypassPermissions". Đặt chúng trong ~/.claude/settings.json
  • Chạy /status để xem file nào đã được nạp (dòng Setting sources)

Lệnh Slash tuỳ chỉnh (Lỗi thời)

Các file markdown tạo ra /lệnh-slash tái sử dụng. Commands đã được gộp vào skillsCommands và skills giờ là cùng một hệ thống. File command .claude/commands/review.md và skill .claude/skills/review/SKILL.md đều tạo ra /review và hoạt động y hệt, nhưng file command có sẵn vẫn chạy và thư mục này vẫn được hỗ trợ.

Bắt đầu nhanh

  1. Tạo một file .md trong .claude/commands/
  2. Viết prompt vào đó. Dùng $ARGUMENTS làm chỗ giữ cho đầu vào của người dùng
  3. Tên file trở thành tên lệnh: review-pr.md tạo ra /review-pr
  4. Gõ / trong Claude Code để xem và chạy các lệnh của bạn

Cách hoạt động

  1. Claude quét .claude/commands/ lúc khởi động và đăng ký mỗi file .md thành một lệnh slash
  2. Khi bạn gọi /tên-lệnh, Claude đọc file và thay $ARGUMENTS bằng những gì bạn gõ sau lệnh
  3. Prompt sau khi mở rộng được gửi cho Claude như thể bạn tự gõ

Commands là hệ thống nguyên bản, đơn giản hơn. Skills là bản thay thế mới hơn, mạnh hơn.

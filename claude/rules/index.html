Rules là gì?

Rules cung cấp quy ước theo ngữ cảnh mà Claude nạp dựa trên file bạn đang sửa.

File liên quan
.claude/rules/my-rule.md
.claude/rules/RULES.md

Rules

Các file markdown cung cấp quy ước theo ngữ cảnhChỉ được nạp vào bối cảnh khi liên quan, dựa trên mẫu file bạn định nghĩa mà Claude tự động nạp. Mỗi rule là một file .md trong .claude/rules/. Khi Claude đọc file khớp với mẫu đường dẫnCú pháp glob chuẩn: * khớp file, ** khớp thư mục, {a,b} khớp các lựa chọn của một rule, rule đó được nạp vào bối cảnh cùng với CLAUDE.md.

Bắt đầu nhanh

  1. Tạo file: .claude/rules/code-style.md
  2. Tuỳ chọn thêm frontmatterKhối YAML ở đầu file giữa hai dấu ---. Chứa trường paths để giới hạn rule theo file cụ thể với paths để giới hạn theo file cụ thể
  3. Viết quy ước vào phần thân
  4. Commit vào git để cả nhóm dùng chung rule

Không cần đăng ký hay cấu hình. Claude tự phát hiện file rule lúc khởi động.

Rules hoạt động thế nào

Rules dùng mô hình so khớp đơn giản:

  1. Khám phá: Lúc khởi động, Claude quét .claude/rules/ đệ quyMọi file .md trong thư mục con cũng được phát hiện, nên bạn có thể tổ chức rule thành thư mục như frontend/ hay backend/ và đọc frontmatter của từng file
  2. So khớp: Khi Claude đọc một file, nó kiểm tra rule nào có mẫu paths khớp. Nếu nhiều rule khớp, tất cả đều được nạp
  3. Nạp: Rule khớp được kéo vào bối cảnh cùng CLAUDE.md. Rule không có paths luôn được nạp

Frontmatter

Rule có thể dùng frontmatter YAML để quyết định khi nào kích hoạt:

yaml
---
paths:
  - "src/**/*.ts"
  - "src/**/*.py"
---
Trường Bắt buộc Mục đích
paths Không Mẫu file kích hoạt rule này. Bỏ trống để luôn nạp

Nếu bỏ hẳn frontmatter, rule luôn được nạp vào bối cảnh với độ ưu tiên như CLAUDE.md.

Rule nằm ở đâu

Vị trí Phạm vi
.claude/rules/ Dự án này (commit vào git)
~/.claude/rules/ Mọi dự án của bạn

Rule cấp người dùng được nạp trước rule dự án, nên rule dự án có độ ưu tiên cao hơn. Thư mục .claude/rules/ cũng hỗ trợ symlinkLiên kết tượng trưng được phân giải và nạp bình thường. Symlink vòng được phát hiện và xử lý êm ái, nên bạn có thể duy trì một bộ rule dùng chung và liên kết vào nhiều dự án.

Dùng CLAUDE.md cho bối cảnh toàn dự án luôn áp dụng. Dùng rules cho quy ước chỉ quan trọng khi làm với loại file cụ thể. Dùng skills cho hành động Claude thực hiện khi cần.

Khuôn mẫu thường gặp

Style guide theo ngôn ngữ: mỗi ngôn ngữ một rule, với paths nhắm vào loại file đó. Quy ước Python chỉ nạp khi Claude đọc file .py.

Quy ước test: khuôn mẫu test chỉ kích hoạt khi làm việc với file test. Giữ rule riêng cho test khỏi bối cảnh khi phát triển bình thường.

Xử lý lỗi: quy ước lỗi giới hạn cho file mã nguồn. Cách báo lỗi, ghi log gì, hiện gì cho người dùng.

Rule bảo mật: kiểm tra đầu vào, xác thực và chính sách phụ thuộc, giới hạn cho các file liên quan.

Chuẩn tài liệu: phong cách comment, định dạng docstring và quy ước README, giới hạn cho các file áp dụng.

Mẹo

  • Giữ rule tập trung. Mỗi file một mối quan tâm, không phải một file khổng lồ chứa mọi thứ
  • Đặt tên file có ý nghĩa: code-style.md, testing.md, error-handling.md
  • Giữ từng file rule ngắn gọn. Mỗi rule được nạp đều tiêu tốn token context cùng với CLAUDE.md
  • Rule không có paths luôn được nạp, nên hãy dùng hạn chế để tránh phình bối cảnh
  • Rules là bối cảnh thụ động. Nếu cần Claude chạy script hay theo quy trình nhiều bước, hãy dùng skillSkills là gói hướng dẫn tái sử dụng với script, tài liệu tham khảo tuỳ chọn, và gọi được bằng /tên-skill
  • Rules bổ sung cho CLAUDE.md. Đặt quy ước chung vào CLAUDE.md, quy ước theo file vào rules
  • Tổ chức rule thành thư mục con (vd. rules/frontend/, rules/backend/) cho dự án lớn. Mọi file .md đều được phát hiện đệ quy

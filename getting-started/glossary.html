Thuật ngữ cần biết

Hai mươi khái niệm bạn sẽ gặp liên tục khi dùng Claude Code, giải thích ngắn gọn bằng tiếng Việt.

Cập nhật 15/11/2026 · 3 phút đọc

Trên site này, nhiều thuật ngữ được giữ nguyên tiếng Anh vì đó là cách cộng đồng và tài liệu gọi chúng. Bảng dưới đây giải thích từng cái, kèm chỗ để đọc sâu hơn trong phần Tham chiếu.

Nền tảng

Thuật ngữ Nghĩa
Agent / agentic AI không chỉ trả lời mà còn hành động: đọc file, chạy lệnh, sửa code, kiểm tra kết quả, rồi quyết định bước tiếp
Vòng lặp agentic Chu trình thu thập bối cảnh → hành động → kiểm chứng, lặp lại cho tới khi xong việc
Harness Lớp bao quanh model: cung cấp công cụ và quản lý những gì model nhìn thấy. Claude Code chính là harness
Tool (công cụ) Khả năng hành động cụ thể: Read, Edit, Bash, Grep, WebFetch… Mỗi lần dùng công cụ trả thông tin về cho vòng lặp
Phiên (session) Một cuộc hội thoại gắn với một thư mục. Mỗi phiên mới bắt đầu với bối cảnh trống
Lượt (turn) Một lần bạn gửi tin và Claude làm việc cho tới khi trả lời xong

Bối cảnh

Thuật ngữ Nghĩa
Context window "Trí nhớ làm việc" của Claude trong một phiên: chỉ dẫn, file đã đọc, output lệnh, hội thoại. Có giới hạn
Token Đơn vị đo văn bản mà model xử lý. Chi phí và hạn mức tính theo token
Compaction Tóm tắt hội thoại cũ để giải phóng chỗ khi context sắp đầy (/compact)
Prompt cache Bộ nhớ đệm phần đầu hội thoại, giúp các request sau rẻ và nhanh hơn
CLAUDE.md File chỉ dẫn được nạp vào mọi phiên: lệnh build, quy ước, lưu ý của dự án
Auto memory Ghi chú Claude tự viết cho mình để nhớ qua các phiên
Effort Mức độ Claude suy nghĩ trước khi trả lời: low tới max

Mở rộng

Thuật ngữ Nghĩa
Skill Gói hướng dẫn tái sử dụng, Claude nạp khi cần hoặc bạn gọi bằng /tên
Subagent Một phiên bản Claude riêng với bối cảnh và công cụ riêng, làm một việc rồi trả bản tóm tắt về
Hook Script Claude Code tự chạy ở thời điểm cố định (trước/sau khi dùng công cụ…), không phụ thuộc Claude có nhớ hay không
MCP Model Context Protocol: chuẩn kết nối Claude với công cụ và dữ liệu bên ngoài (Slack, Notion, database…)
Plugin Gói skills, agents, hooks, MCP để chia sẻ cho người khác

An toàn

Thuật ngữ Nghĩa
Chế độ quyền (permission mode) Mức Claude được tự làm trước khi hỏi: Manual, Accept Edits, Plan, Auto…
Rule allow / ask / deny Luật trong settings cho phép, buộc hỏi hoặc chặn hẳn một công cụ hay lệnh cụ thể
Checkpoint Ảnh chụp file trước khi Claude sửa, để quay lại bằng /rewind
Sandbox Giới hạn cấp hệ điều hành về file và mạng cho lệnh shell của Claude

Một phân biệt quan trọng

Có hai loại chỉ dẫn, và hiểu khác biệt này giúp bạn chọn đúng công cụ:

  • Claude quyết định (không tất định): prompt, CLAUDE.md, skill. Claude gần như luôn làm theo, nhưng không có bảo đảm tuyệt đối.
  • Claude Code cưỡng chế (tất định): hook, rule deny, managed settings. Luôn được áp dụng, bất kể model nghĩ gì.

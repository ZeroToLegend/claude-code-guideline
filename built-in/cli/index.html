# CLI & Headless

Claude Code trước hết là một công cụ dòng lệnh. Cách bạn khởi chạy `claude` quyết định loại phiên bạn có: phiên terminal tương tác, hoặc một lượt [chạy headless](^Chạy prompt, in kết quả rồi thoát, không có giao diện tương tác. Còn gọi là print mode) in kết quả rồi thoát, dành cho script và CI.

## Hai cách chạy

| Lệnh | Bạn nhận được |
|---|---|
| `claude` | Một phiên tương tác |
| `claude "explain this project"` | Tương tác, kèm prompt mở đầu |
| `claude -p "explain this function"` | Headless: in câu trả lời rồi thoát |
| `cat log.txt \| claude -p "explain"` | Headless, đọc đầu vào từ pipe |

Cờ [`-p`](^Viết tắt của --print. Chạy không tương tác rồi thoát. Xem mục Headless Mode) là công tắc giữa hai cách. Mọi cờ khác đều dùng được với cả hai.

## Lệnh con

Ngoài việc bắt đầu phiên, `claude` có các lệnh con để quản lý:

| Lệnh | Tác dụng |
|---|---|
| `claude update` | Cập nhật lên phiên bản mới nhất |
| `claude doctor` | In chẩn đoán cài đặt và settings |
| `claude mcp` | Cấu hình [MCP server](^Server Model Context Protocol kết nối Claude với công cụ bên ngoài. Xem mục MCP) |
| `claude auth login` | Đăng nhập tài khoản Anthropic |
| `claude agents` | Mở [agent view](^Bảng điều khiển cho các phiên nền chạy tách khỏi terminal của bạn) cho các phiên nền |
| `claude setup-token` | Tạo token dài hạn cho CI |

## Khám phá

Mở các mục bên dưới:

- **Cờ (Flags)** trình bày các tuỳ chọn quan trọng: chọn model, đặt chế độ quyền, thêm thư mục, và định hình system prompt
- **Headless Mode** trình bày `claude -p` cho script và CI: đầu ra có cấu trúc, piping và bare mode

Cờ (Flags)

Những cờ bạn thật sự sẽ dùng, nhóm theo chức năng. Chúng chạy được cả trong phiên tương tác lẫn headlessPrint mode: claude -p. Xem mục Headless Mode. Danh sách đầy đủ có ở tài liệu chính thức cuối trang.

Phiên

Cờ Tác dụng
-c, --continue Tiếp tục hội thoại gần nhất trong thư mục này
-r, --resume <id> Tiếp tục một phiên cụ thể theo ID hoặc tên, hoặc mở bộ chọn
-n, --name <name> Đặt tên phiên để sau này tìm và tiếp tục
--fork-session Tiếp tục vào một ID phiên mới, giữ nguyên phiên gốc
--from-pr <number> Lọc bộ chọn tiếp tục theo các phiên gắn với một pull request

Model và Effort

Cờ Tác dụng
--model <alias> Đặt model: sonnet, opus, haiku, fable, hoặc tên đầy đủ
--effort <level> Đặt mức effort suy luậnModel suy nghĩ kỹ đến đâu: low, medium, high, xhigh, max. Xem Context & Thinking
--fallback-model <m> Chuyển sang model khác khi model đầu bị quá tải

Quyền và truy cập

Cờ Tác dụng
--permission-mode <mode> Khởi động ở một chế độdefault, acceptEdits, plan, auto, dontAsk, bypassPermissions. Xem mục Chế độ như plan hoặc acceptEdits
--allowedTools <list> Duyệt trước công cụ để chúng chạy không cần hỏi, như "Bash(git diff *),Read"
--add-dir <paths> Cho Claude truy cập thư mục ngoài thư mục hiện tại
--dangerously-skip-permissions Bỏ qua mọi lần xin quyền. Chỉ dùng trong môi trường cô lập

Bối cảnh và hành vi

Cờ Tác dụng
--append-system-prompt <text> Thêm vào system prompt mặc định, giữ hành vi của Claude Code
--system-prompt <text> Thay hoàn toàn system prompt
--settings <file-or-json> Nạp settings từ file hoặc JSON trực tiếp
--mcp-config <file> Nạp MCP serverKết nối công cụ bên ngoài. Xem mục MCP cho lần chạy này
--agents <json> Định nghĩa subagentAgent tuỳ chỉnh với prompt và công cụ riêng. Xem mục agents trực tiếp

Đầu ra và chẩn đoán

Cờ Tác dụng
-p, --print Chạy headlessIn kết quả rồi thoát, không có giao diện tương tác. Xem mục Headless Mode rồi thoát
--output-format <fmt> text, json hoặc stream-json, khi chạy headless
--verbose Output đầy đủ từng lượt
--debug [filter] Log chẩn đoán, có thể lọc như "api,mcp"
-v, --version In phiên bản

Mẹo

  • Bí danh giúp gõ ngắn: -c cho --continue, -r cho --resume, -p cho --print
  • --model và --effort cũng đổi được giữa phiên bằng /model và /effort
  • Ưu tiên --append-system-prompt hơn --system-prompt. Nó thêm chỉ dẫn mà không bỏ hành vi tích hợp của Claude Code

# Cờ (Flags)

Những cờ bạn thật sự sẽ dùng, nhóm theo chức năng. Chúng chạy được cả trong phiên tương tác lẫn [headless](^Print mode: claude -p. Xem mục Headless Mode). Danh sách đầy đủ có ở tài liệu chính thức cuối trang.

## Phiên

| Cờ | Tác dụng |
|---|---|
| `-c`, `--continue` | Tiếp tục hội thoại gần nhất trong thư mục này |
| `-r`, `--resume <id>` | Tiếp tục một phiên cụ thể theo ID hoặc tên, hoặc mở bộ chọn |
| `-n`, `--name <name>` | Đặt tên phiên để sau này tìm và tiếp tục |
| `--fork-session` | Tiếp tục vào một ID phiên mới, giữ nguyên phiên gốc |
| `--from-pr <number>` | Lọc bộ chọn tiếp tục theo các phiên gắn với một pull request |

## Model và Effort

| Cờ | Tác dụng |
|---|---|
| `--model <alias>` | Đặt model: `sonnet`, `opus`, `haiku`, `fable`, hoặc tên đầy đủ |
| `--effort <level>` | Đặt [mức effort suy luận](^Model suy nghĩ kỹ đến đâu: low, medium, high, xhigh, max. Xem Context & Thinking) |
| `--fallback-model <m>` | Chuyển sang model khác khi model đầu bị quá tải |

## Quyền và truy cập

| Cờ | Tác dụng |
|---|---|
| `--permission-mode <mode>` | Khởi động ở một [chế độ](^default, acceptEdits, plan, auto, dontAsk, bypassPermissions. Xem mục Chế độ) như `plan` hoặc `acceptEdits` |
| `--allowedTools <list>` | Duyệt trước công cụ để chúng chạy không cần hỏi, như `"Bash(git diff *),Read"` |
| `--add-dir <paths>` | Cho Claude truy cập thư mục ngoài thư mục hiện tại |
| `--dangerously-skip-permissions` | Bỏ qua mọi lần xin quyền. Chỉ dùng trong môi trường cô lập |

## Bối cảnh và hành vi

| Cờ | Tác dụng |
|---|---|
| `--append-system-prompt <text>` | Thêm vào system prompt mặc định, giữ hành vi của Claude Code |
| `--system-prompt <text>` | Thay hoàn toàn system prompt |
| `--settings <file-or-json>` | Nạp settings từ file hoặc JSON trực tiếp |
| `--mcp-config <file>` | Nạp [MCP server](^Kết nối công cụ bên ngoài. Xem mục MCP) cho lần chạy này |
| `--agents <json>` | Định nghĩa [subagent](^Agent tuỳ chỉnh với prompt và công cụ riêng. Xem mục agents) trực tiếp |

## Đầu ra và chẩn đoán

| Cờ | Tác dụng |
|---|---|
| `-p`, `--print` | Chạy [headless](^In kết quả rồi thoát, không có giao diện tương tác. Xem mục Headless Mode) rồi thoát |
| `--output-format <fmt>` | `text`, `json` hoặc `stream-json`, khi chạy headless |
| `--verbose` | Output đầy đủ từng lượt |
| `--debug [filter]` | Log chẩn đoán, có thể lọc như `"api,mcp"` |
| `-v`, `--version` | In phiên bản |

## Mẹo

- Bí danh giúp gõ ngắn: `-c` cho `--continue`, `-r` cho `--resume`, `-p` cho `--print`
- `--model` và `--effort` cũng đổi được giữa phiên bằng `/model` và `/effort`
- Ưu tiên `--append-system-prompt` hơn `--system-prompt`. Nó thêm chỉ dẫn mà không bỏ hành vi tích hợp của Claude Code

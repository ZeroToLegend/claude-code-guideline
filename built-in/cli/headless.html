Headless Mode

claude -p cho script và CI: định dạng đầu ra, structured output, piping và bare mode.

Headless Mode

Thêm -p (hoặc --print) vào bất kỳ lệnh claude nào để chạy không tương tác. Claude chạy prompt, in kết quả rồi thoát. Đây là cách dùng Claude Code trong script, bước build và CI.

bash
claude -p "Module auth làm gì?"

Mọi cờ CLIXem mục Cờ đều dùng được với -p, gồm --allowedTools, --continue và --output-format.

Định dạng đầu ra

--output-format quyết định bạn nhận lại gì:

Định dạng Trả về
text Văn bản thuần, mặc định
json JSON có cấu trúc: kết quả, session ID, chi phí và metadata sử dụng
stream-json Các sự kiện JSON phân tách bằng dòng mới, để stream trong lúc Claude làm việc

Với json, payload có total_cost_usd và chi phí chia theo model, nên script có thể theo dõi chi tiêu mỗi lần gọi:

bash
claude -p "Tóm tắt dự án này" --output-format json | jq -r '.result'

Đầu ra có cấu trúc

Kết hợp --output-format json với --json-schema để buộc kết quả theo khuôn bạn định nghĩa. Giá trị có cấu trúc nằm trong trường structured_output:

bash
claude -p "Trích tên các hàm trong auth.py" \
  --output-format json \
  --json-schema '{"type":"object","properties":{"functions":{"type":"array","items":{"type":"string"}}},"required":["functions"]}'

Piping vào và ra

Headless mode đọc standard input, nên bạn có thể pipe dữ liệu vào và chuyển hướng kết quả ra như mọi công cụ dòng lệnh:

bash
cat build-error.txt | claude -p "giải thích nguyên nhân gốc của lỗi build này" > output.txt

Pipe một diff là khuôn mẫu CI phổ biến, vì Claude không cần quyền để đọc thứ bạn đưa vào:

bash
git diff main | claude -p "bạn là linter lỗi chính tả. báo filename:line cho mỗi lỗi."

Bare Mode cho CI

Thêm --bareBỏ qua việc tự phát hiện hooks, skills, plugins, MCP server, auto memory và CLAUDE.md. Chỉ những cờ bạn truyền tường minh mới có hiệu lực để bỏ qua tự phát hiện và khởi động nhanh hơn. Không có nó, claude -p nạp cùng bối cảnh như phiên tương tác, kể cả hooks hay MCP server nào tình cờ được cấu hình cục bộ. Bare mode cho cùng kết quả trên mọi máy, đúng thứ bạn muốn trong CI:

bash
claude --bare -p "Tóm tắt file này" --allowedTools "Read"

Tiếp tục hội thoại

Các lượt chạy headless có thể nối chuỗi. Dùng --continue cho phiên gần nhất, hoặc lấy session ID để tiếp tục một phiên cụ thể:

bash
session_id=$(claude -p "Bắt đầu review" --output-format json | jq -r '.session_id')
claude -p "Giờ tập trung vào các truy vấn database" --resume "$session_id"

Mẹo

  • Đặt trần: --max-budget-usd 5.00 giới hạn chi tiêu và --max-turns 3 giới hạn số lượt agentic
  • Duyệt trước công cụ bằng --allowedTools, hoặc đặt mức nền khoá chặt bằng --permission-mode dontAsk
  • --bare là chế độ khuyên dùng cho lời gọi từ script và sẽ thành mặc định của -p trong một bản phát hành tương lai

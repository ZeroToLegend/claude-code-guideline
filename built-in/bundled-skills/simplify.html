  2. Chất lượng code - bắt bug, đặt tên khó hiểu, thiếu xử lý lỗi và vấn đề phong cách

Sau khi cả ba agent báo lại, Claude tổng hợp phát hiện, loại bỏ vấn đề trùng nhau, và áp dụng bản sửa trực tiếp.

# /simplify

Review các file bạn vừa thay đổi để tìm vấn đề về tái sử dụng code, chất lượng và hiệu năng, rồi sửa chúng. Chạy nó sau khi làm xong một tính năng hoặc sửa bug để dọn dẹp thành quả.

## Cách hoạt động

Khi bạn gọi `/simplify`, Claude sinh **ba agent review song song**:

1. **Tái sử dụng code** - tìm logic trùng lặp, abstraction bị bỏ lỡ, và cơ hội dùng chung code
2. **Chất lượng code** - bắt bug, đặt tên khó hiểu, thiếu xử lý lỗi và vấn đề phong cách
3. **Hiệu năng** - phát hiện cấp phát thừa, tính toán dư thừa và các bẫy hiệu năng

Sau khi cả ba agent báo lại, Claude tổng hợp phát hiện, loại bỏ vấn đề trùng nhau, và áp dụng bản sửa trực tiếp.

## Cách dùng

```
/simplify
```

Tập trung review vào mối quan tâm cụ thể:

```
/simplify tập trung vào hiệu quả bộ nhớ
/simplify chỉ kiểm tra tái sử dụng code trong module auth
```

## Khi nào dùng

- Sau khi hoàn thành tính năng hoặc sửa bug, trước khi commit
- Khi bạn đã lặp nhanh và muốn một lượt dọn dẹp
- Sau một đợt refactor lớn để bắt những gì bạn bỏ sót
- Trước khi mở pull request

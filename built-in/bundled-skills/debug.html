# /debug

Chẩn đoán phiên Claude Code hiện tại bằng cách đọc debug log của phiên. Bạn có thể mô tả vấn đề để tập trung phân tích.

## Cách dùng

```
/debug
/debug vì sao lời gọi công cụ vừa rồi thất bại?
/debug MCP server không kết nối được
```

## Cách hoạt động

Claude đọc debug log nội bộ của phiên hiện tại và phân tích để tìm:

- **Lời gọi công cụ thất bại** và nguyên nhân gốc
- Vấn đề kết nối **MCP server**
- **Từ chối quyền** và lý do xảy ra
- Các khuôn mẫu **hành vi bất thường**

Debug log chứa thông tin chi tiết về mọi lời gọi công cụ, request API và sự kiện nội bộ trong phiên. Nhiều hơn rất nhiều so với những gì hiện trong hội thoại.

## Khi nào dùng

- Khi một lời gọi công cụ thất bại và thông báo lỗi không rõ ràng
- Khi MCP server không kết nối hoặc phản hồi không như mong đợi
- Khi hành vi của Claude có vẻ sai và bạn muốn hiểu vì sao
- Khi cần báo bug và muốn có bối cảnh chẩn đoán

## Mẹo

- Mô tả vấn đề để tập trung phân tích: `/debug vì sao Claude không đọc được file .env của tôi` hữu ích hơn chỉ `/debug`
- Chạy ngay sau khi gặp sự cố. Debug log gắn với phiên và không còn sau khi khởi động lại

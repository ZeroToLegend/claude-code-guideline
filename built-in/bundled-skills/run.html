# /run

Khởi chạy và điều khiển app của dự án để bạn thấy một thay đổi thật sự hoạt động, không chỉ pass test.

## Cách dùng

```
/run
```

Yêu cầu nó chạy, khởi động hoặc chụp màn hình app, hoặc xác nhận một thay đổi hoạt động trên bản thật.

## Cách hoạt động

`/run` trước tiên tìm một [skill dự án](^Một skill trong .claude/skills/ đã biết cách khởi chạy app này. Xem mục skills) đã biết cách khởi chạy app của bạn. Nếu không có, nó dùng các khuôn mẫu có sẵn theo loại dự án:

| Loại dự án | Nó làm gì |
|---|---|
| CLI | Chạy lệnh và ghi lại output |
| Server | Khởi động server và gọi thử một endpoint |
| TUI | Khởi chạy và điều khiển giao diện terminal |
| Electron hoặc desktop | Khởi động app |
| Chạy trên trình duyệt | Mở và tương tác với trang |
| Thư viện | Chạy một ví dụ hoặc smoke test |

## Khi nào dùng

- Xác nhận một thay đổi hoạt động trong app đang chạy, ngoài phạm vi bộ test bao phủ
- Tái hiện bug trên bản thật trước khi sửa
- Chụp màn hình trạng thái hiện tại của UI

## Mẹo

- Nếu app khởi chạy theo cách không chuẩn, dạy `/run` một lần bằng một skill dự án và nó sẽ dùng lại
- Kết hợp với test, đừng thay thế test. `/run` kiểm chứng trải nghiệm thật; test kiểm chứng logic
- Đây là cách nhanh để khép vòng: thay đổi, rồi xem nó thật sự chạy

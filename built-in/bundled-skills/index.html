Bundled Skills

Bundled skills đi kèm Claude Code và có sẵn trong mọi phiên. Khác với skill tuỳ chỉnhSkills bạn tạo trong .claude/skills/ - xem mục skills phía trên bạn xây trong .claude/skills/, bundled skills là playbook dựa trên prompt do Anthropic duy trì. Chúng đưa cho Claude một bộ hướng dẫn chi tiết và để nó điều phối công việc bằng công cụ của mình: sinh agent song song, đọc file và thích ứng với codebase của bạn.

Bạn gọi bundled skill giống mọi skill khác: gõ / rồi tên skill.

Các skill có sẵn

Skill Tác dụng
/simplify Sinh 3 agent review song song để kiểm tra tái sử dụng, chất lượng và hiệu năng
/batch <chỉ dẫn> Tách thay đổi lớn thành các đơn vị độc lập, chạy mỗi đơn vị trong một worktree
/debug [mô tả] Đọc debug log của phiên để chẩn đoán sự cố
/loop [chu kỳ] <prompt> Lên lịch một tác vụ cron định kỳ để chạy lại prompt theo chu kỳ

# Bundled Skills

Bundled skills đi kèm Claude Code và có sẵn trong mọi phiên. Khác với [skill tuỳ chỉnh](^Skills bạn tạo trong .claude/skills/ - xem mục skills phía trên) bạn xây trong `.claude/skills/`, bundled skills là **playbook dựa trên prompt** do Anthropic duy trì. Chúng đưa cho Claude một bộ hướng dẫn chi tiết và để nó điều phối công việc bằng công cụ của mình: sinh agent song song, đọc file và thích ứng với codebase của bạn.

Bạn gọi bundled skill giống mọi skill khác: gõ `/` rồi tên skill.

| `/loop [chu kỳ] <prompt>` | Lên lịch một tác vụ cron định kỳ để chạy lại prompt theo chu kỳ |
| `/claude-api` | Nạp tài liệu API và SDK cho ngôn ngữ của dự án |
| `/code-review` | Review diff hiện tại tìm lỗi đúng/sai, có nâng cấp `ultra` trên cloud |
| `/security-review` | Kiểm tra lỗ hổng bảo mật trong các thay đổi đang chờ |

# /claude-api

Nạp tài liệu tham chiếu Claude API cho ngôn ngữ của dự án và tài liệu [Agent SDK](^Bộ công cụ để xây agent tuỳ chỉnh dùng Claude làm bộ máy suy luận. Có cho Python và TypeScript). Bao gồm tool use, streaming, batches, structured output và các lỗi thường gặp.

## Cách dùng

```
/claude-api
```

Hoặc nó **tự kích hoạt** khi code của bạn import:

- `anthropic` (Python)
- `@anthropic-ai/sdk` (TypeScript/JavaScript)
- `claude_agent_sdk` (Agent SDK)

## Ngôn ngữ được hỗ trợ

| Ngôn ngữ | SDK |
|---|---|
| Python | `anthropic` |
| TypeScript | `@anthropic-ai/sdk` |
| Java | Anthropic Java SDK |
| Go | Anthropic Go SDK |
| Ruby | Anthropic Ruby SDK |
| C# | Anthropic .NET SDK |
| PHP | Anthropic PHP SDK |
| cURL | HTTP API thô |

## Bao gồm những gì

- **Tool use** - định nghĩa công cụ, xử lý kết quả công cụ, gọi công cụ song song
- **Streaming** - server-sent events, streaming kèm tool use
- **Batches** - tạo và quản lý Message Batches
- **Structured output** - dùng JSON mode và constrained decoding
- **Agent SDK** - xây agent tuỳ chỉnh bằng Python và TypeScript
- **Lỗi thường gặp** - rate limit, đếm token, khuôn mẫu xử lý lỗi

## Khi nào dùng

- Khi xây ứng dụng gọi Claude API
- Khi triển khai tool use hoặc streaming trong app
- Khi dùng Agent SDK cho quy trình agent tuỳ chỉnh
- Khi cần cú pháp riêng của SDK cho ngôn ngữ của bạn

## Tự kích hoạt

Trong đa số trường hợp bạn không cần gọi `/claude-api` thủ công. Nếu Claude phát hiện code của bạn import `anthropic`, `@anthropic-ai/sdk` hoặc `claude_agent_sdk`, nó tự nạp tài liệu API tương ứng. Nghĩa là Claude đã có bối cảnh API khi bạn làm việc với code giao tiếp với Claude.

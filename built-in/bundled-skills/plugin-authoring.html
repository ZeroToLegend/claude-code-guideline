# /plugin-authoring

Xây một [mod](^Một file JavaScript hoặc TypeScript nhỏ chạy bên trong phiên của bạn. Xem .claude/mods) cho bạn: một pane sống, một dải phía trên ô prompt, một status line, một toast, hoặc một hook. Nó viết mod dưới dạng plugin gồm các function hook, nạp nóng vào chính phiên bạn đang dùng.

## Cách dùng

Bạn hiếm khi phải gõ nó. Hãy mô tả mod bạn muốn và Claude tự nạp skill:

```
> tạo một mod hiển thị context window đang đầy bao nhiêu, phía trên ô prompt
> thêm một pane liệt kê mọi file Claude đã sửa trong lượt này
> giữ lại mọi lệnh git reset --hard và cho tôi xem nó sẽ vứt bỏ những gì
```

Bạn cũng có thể gọi trực tiếp bằng `/plugin-authoring`.

## Nó làm gì

| Bước | Điều gì xảy ra |
|---|---|
| Dựng khung | Tạo `.claude-plugin/plugin.json`, `hooks/hooks.json` và module |
| Kiểu | Viết `types/index.d.ts` khai báo mọi khoá `$.state` mà mod dùng |
| Nạp | Nạp mod vào phiên hiện tại với hot reload bật |
| Lặp | Sửa module khi bạn góp ý. Mỗi lần lưu là nạp lại tại chỗ |
| Debug | Đọc lỗi của mod và sửa hook bị lỗi |

## Khi nào dùng

- Bạn muốn UI tuỳ chỉnh trong terminal hoặc tab Code của desktop app
- Shell hook là chưa đủ vì bạn cần trạng thái giữa các sự kiện hoặc cập nhật trực tiếp
- Bạn muốn thử nhanh một ý tưởng trước khi quyết định có chia sẻ hay không

## Mẹo

- Nói rõ bạn muốn bề mặt nào (band, pane, status line, toast). Nó thay đổi code rất nhiều
- Yêu cầu cả test. Skill có thể viết `tests/*.test.ts` cho `claude plugin test`
- Khi đã hài lòng, chạy `claude plugin validate` và thêm vào một marketplace để chia sẻ

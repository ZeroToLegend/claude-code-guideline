Phím tắt

Tham chiếu bàn phím đầy đủ cho một phiên Claude Code. Chúng có sẵn, và một số ít khác nhau theo nền tảng, được ghi chú ngay trong bảng. Phím nào cũng có thể gán lạiTuỳ biến mọi phím tắt trong ~/.claude/keybindings.json. Xem mục Keybindings nếu mặc định không hợp với bạn.

# Phím tắt

Tham chiếu bàn phím đầy đủ cho một phiên Claude Code. Chúng có sẵn, và một số ít khác nhau theo nền tảng, được ghi chú ngay trong bảng. Phím nào cũng có thể [gán lại](^Tuỳ biến mọi phím tắt trong ~/.claude/keybindings.json. Xem mục Keybindings) nếu mặc định không hợp với bạn.

## Điều khiển chung

| Phím | Tác dụng |
|---|---|
| `Ctrl+C` | Ngắt thao tác đang chạy. Ở prompt rảnh, nhấn lần đầu xoá ô nhập, lần hai thì thoát |
| `Esc` | Ngắt Claude giữa lượt, hoặc đóng hộp thoại đang mở |
| `Esc` `Esc` | Khi prompt trống, mở [menu rewind](^Khôi phục hoặc tóm tắt code và hội thoại từ một điểm trước đó. Xem Checkpointing). Khi có chữ, xoá bản nháp và lưu vào lịch sử |
| `Ctrl+D` | Thoát Claude Code. Khi prompt có chữ, thay vào đó xoá ký tự sau con trỏ |
| `Shift+Tab` | Xoay vòng [chế độ quyền](^Manual, Accept Edits, Plan, và các chế độ bạn đã bật. Xem mục Chế độ) |
| `Ctrl+B` | Đưa tác vụ đang chạy xuống nền. Người dùng tmux nhấn hai lần |
| `Ctrl+O` | Bật/tắt trình xem transcript |
| `Ctrl+R` | Tìm ngược trong lịch sử lệnh |
| `Ctrl+L` | Vẽ lại màn hình mà không mất ô nhập hay lịch sử |
| `Ctrl+T` | Bật/tắt [danh sách việc](^Danh sách việc cần làm của chính Claude cho công việc nhiều bước. Không phải màn hình tác vụ nền, đó là /tasks) của Claude |
| `Ctrl+S` | Cất tạm prompt hiện tại, hoặc khôi phục prompt đã cất |
| `Ctrl+G` | Mở prompt trong trình soạn thảo văn bản mặc định |
| `Ctrl+V` | Dán ảnh từ clipboard (`Alt+V` trên Windows và WSL) |
| `Ctrl+Z` | Tạm dừng Claude Code để về shell trên Unix. Chạy `fg` để tiếp tục |
| `Up` / `Down` | Di chuyển con trỏ trong ô nhập nhiều dòng, rồi duyệt lịch sử lệnh khi ở mép |

### Model, Thinking và Fast Mode

Các phím này dùng `Option` trên macOS và `Alt` trên Windows và Linux:

| Phím | Tác dụng |
|---|---|
| `Option+P` / `Alt+P` | Đổi model mà không xoá prompt |
| `Option+T` / `Alt+T` | Bật/tắt [extended thinking](^Mức độ Claude suy luận trước khi trả lời. Xem Context & Thinking) |
| `Option+O` / `Alt+O` | Bật/tắt [fast mode](^Cùng model Opus nhưng xuất kết quả nhanh hơn. Bật/tắt bằng /fast) |

## Sửa văn bản

Ô prompt hỗ trợ các phím sửa chuẩn của readline:

| Phím | Tác dụng |
|---|---|
| `Ctrl+A` / `Ctrl+E` | Nhảy về đầu / cuối dòng |
| `Ctrl+K` | Xoá từ con trỏ tới cuối dòng |
| `Ctrl+U` | Xoá từ con trỏ tới đầu dòng |
| `Ctrl+W` | Xoá từ phía trước |
| `Ctrl+Y` | Dán lại văn bản đã xoá bằng `Ctrl+K`, `Ctrl+U` hoặc `Ctrl+W` |
| `Alt+B` / `Alt+F` | Lùi / tiến một từ |
| `Ctrl+_` | Hoàn tác lần sửa ô nhập gần nhất |

## Nhập nhiều dòng

Để viết prompt trên nhiều dòng:

| Cách | Làm thế nào |
|---|---|
| Thoát nhanh | `\` rồi `Enter`. Chạy trên mọi terminal |
| Chuỗi điều khiển | `Ctrl+J`. Chạy trên mọi terminal, không cần thiết lập |
| Shift+Enter | Có sẵn trong iTerm2, WezTerm, Ghostty, Kitty, Warp, Apple Terminal và Windows Terminal |
| Option+Enter | Trên macOS khi bật [Option as Meta](^Cấu hình terminal coi phím Option là phím Meta) |

Với VS Code, Cursor, Alacritty và Zed, chạy `/terminal-setup` một lần để cài phím `Shift+Enter`.

## Trình xem transcript

Nhấn `Ctrl+O` để mở trình xem transcript, hiện lời gọi công cụ, thời gian và model dùng cho mỗi tin nhắn:

| Phím | Tác dụng |
|---|---|
| `Ctrl+E` | Bật/tắt hiện toàn bộ nội dung |
| `{` / `}` | Nhảy tới prompt trước / sau, ở [chế độ hiển thị toàn màn hình](^Bộ hiển thị TUI toàn cửa sổ. Chạy /tui để xem bộ hiển thị nào đang dùng) |
| `?` | Hiện bảng phím tắt đầy đủ, ở chế độ hiển thị toàn màn hình |
| `q`, `Ctrl+C`, `Esc` | Thoát trình xem |

## Mẹo

- Trên macOS, phím tắt dùng `Option` cần [cấu hình Option thành Meta](^Một cài đặt của terminal. iTerm2, Apple Terminal và VS Code đều có), nếu không chúng sẽ không ăn
- `Ctrl+B` là phím tiền tố của tmux, nên trong tmux bạn nhấn hai lần để tới chức năng đưa xuống nền của Claude Code
- Gõ `?` khi prompt trống bất cứ lúc nào để bật bảng trợ giúp phím tắt

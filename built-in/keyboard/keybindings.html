Keybindings

Mọi phím tắt trong Claude Code đều gán lại được. Chạy /keybindings để tạo hoặc mở file cấu hình tại ~/.claude/keybindings.json. Thay đổi được phát hiện và áp dụng không cần khởi động lạiLưu file và phím mới có hiệu lực ngay trong phiên đang chạy.

File cấu hình

File là một object có mảng bindings. Mỗi khối đặt tên một contextNơi phím áp dụng: ô nhập chat, hộp thoại xác nhận, trình xem transcript, v.v. và ánh xạ tổ hợp phím tới action:

json
{
  "$schema": "https://www.schemastore.org/claude-code-keybindings.json",
  "bindings": [
    {
      "context": "Chat",
      "bindings": {
        "ctrl+e": "chat:externalEditor",
        "ctrl+u": null
      }
    }
  ]
}

Đoạn này gán Ctrl+E để mở editor ngoài từ ô nhập chat, và gỡ Ctrl+U. Dòng $schema tuỳ chọn giúp editor của bạn tự hoàn thành tên context và action.

Context và Action

Một phím chỉ kích hoạt trong context của nó, nên cùng một phím có thể làm việc khác nhau ở ô nhập chat và ở hộp thoại. Các context thường gặp:

Context Áp dụng ở đâu
Global Mọi nơi trong ứng dụng
Chat Ô nhập prompt chính
Transcript Trình xem transcript
Confirmation Hộp thoại xin quyền và xác nhận
HistorySearch Chế độ tìm lịch sử (Ctrl+R)

Action dùng định dạng namespace:action, như chat:submit để gửi tin nhắn, app:toggleTodos để hiện danh sách việc, hoặc voice:pushToTalk để đọc chính tả. Mỗi context có bộ action riêng.

# Keybindings

Mọi phím tắt trong Claude Code đều gán lại được. Chạy `/keybindings` để tạo hoặc mở file cấu hình tại `~/.claude/keybindings.json`. Thay đổi được phát hiện và áp dụng [không cần khởi động lại](^Lưu file và phím mới có hiệu lực ngay trong phiên đang chạy).

## File cấu hình

File là một object có mảng `bindings`. Mỗi khối đặt tên một [context](^Nơi phím áp dụng: ô nhập chat, hộp thoại xác nhận, trình xem transcript, v.v.) và ánh xạ tổ hợp phím tới action:

```json
{
  "$schema": "https://www.schemastore.org/claude-code-keybindings.json",
  "bindings": [
    {
      "context": "Chat",
      "bindings": {
        "ctrl+e": "chat:externalEditor",
        "ctrl+u": null
      }
    }
  ]
}
```

Đoạn này gán `Ctrl+E` để mở editor ngoài từ ô nhập chat, và gỡ `Ctrl+U`. Dòng `$schema` tuỳ chọn giúp editor của bạn tự hoàn thành tên context và action.

## Context và Action

Một phím chỉ kích hoạt trong context của nó, nên cùng một phím có thể làm việc khác nhau ở ô nhập chat và ở hộp thoại. Các context thường gặp:

| Context | Áp dụng ở đâu |
|---|---|
| `Global` | Mọi nơi trong ứng dụng |
| `Chat` | Ô nhập prompt chính |
| `Transcript` | Trình xem transcript |
| `Confirmation` | Hộp thoại xin quyền và xác nhận |
| `HistorySearch` | Chế độ tìm lịch sử (`Ctrl+R`) |

Action dùng định dạng `namespace:action`, như `chat:submit` để gửi tin nhắn, `app:toggleTodos` để hiện danh sách việc, hoặc `voice:pushToTalk` để đọc chính tả. Mỗi context có bộ action riêng.

## Cú pháp tổ hợp phím

| Thành phần | Quy tắc |
|---|---|
| Phím bổ trợ | Nối bằng `+`: `ctrl+k`, `shift+tab`, `ctrl+shift+c` |
| `meta` | `Alt` trên Windows và Linux, `Option` trên macOS |
| Chữ in hoa | `K` đứng riêng nghĩa là `shift+k`. Khi có phím bổ trợ, `ctrl+K` chỉ là `ctrl+k` |
| Chord | Chuỗi phím cách nhau bằng dấu cách: `ctrl+k ctrl+s` nghĩa là nhấn một tổ hợp, thả ra, rồi nhấn tổ hợp kia |
| Phím đặc biệt | `escape`, `enter`, `tab`, `space`, phím mũi tên, `backspace`, `delete` |

## Gỡ phím

Đặt action thành `null` để bỏ một phím tắt mặc định. Để dùng lại một [tiền tố chord](^Phím như Ctrl+X chỉ dùng để bắt đầu chuỗi nhiều phím) như phím đơn, hãy gỡ mọi chord dùng nó, ở mọi context có định nghĩa nó.

## Những phím không gán lại được

| Phím dành riêng | Lý do |
|---|---|
| `Ctrl+C` | Ngắt được cài cứng |
| `Ctrl+D` | Thoát được cài cứng |
| `Ctrl+M` | Giống hệt Enter trong terminal |
| Caps Lock | Không bao giờ được gửi tới ứng dụng terminal |

[Phím vim](^Di chuyển con trỏ và toán tử trong chế độ soạn thảo vim. Xem mục Vim Mode) cũng cố định. Chúng nằm ở tầng ô nhập văn bản, bên dưới hệ thống keybinding, nên hãy gán lại chúng bằng cài đặt `vimInsertModeRemaps`.

## Nạp từ đâu

Keybindings chỉ được nạp từ `~/.claude/keybindings.json`. Các mục trong `.claude/settings.json` của dự án bị bỏ qua, nên [một repository bạn clone về không thể gán lại phím của bạn](^Một ranh giới an toàn có chủ đích: file dự án được checkout không bao giờ thay đổi phím tắt cục bộ của bạn).

## Mẹo

- Chạy `/keybindings` để tạo khung file với sẵn dòng schema
- Claude Code cảnh báo phím trùng hoặc xung đột khi nạp file. Khởi động với [`--debug`](^Cờ khởi chạy hiện log chẩn đoán, gồm cả cảnh báo keybinding) để xem chi tiết
- Một số phím đụng với terminal multiplexer: `Ctrl+B` là tiền tố của tmux và `Ctrl+A` là của GNU screen. Nhấn hai lần, hoặc gán lại

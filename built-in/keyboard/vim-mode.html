Ba mode

Mode Bạn đang Vào bằng
INSERT Gõ văn bản bình thường i, a, o, và bạn bắt đầu ở đây
NORMAL Di chuyển và chạy operator Esc
VISUAL Chọn văn bản v cho ký tự, V cho dòng

Phím Motion

# Vim Mode

Thích sửa prompt theo cách bạn sửa code? Claude Code có trình soạn kiểu vim cho dòng nhập. Bật trong `/config` ở mục **Editor mode**, rồi sửa bằng các motion và operator bạn đã quen. Nó chỉ đổi cách bạn gõ prompt, không đổi việc Claude làm.

## Ba mode

| Mode | Bạn đang | Vào bằng |
|---|---|---|
| INSERT | Gõ văn bản bình thường | `i`, `a`, `o`, và bạn bắt đầu ở đây |
| NORMAL | Di chuyển và chạy operator | `Esc` |
| VISUAL | Chọn văn bản | `v` cho ký tự, `V` cho dòng |

Ở NORMAL mode, `Esc` không ngắt Claude. Nó chỉ [ở nguyên NORMAL mode](^Phím Escape của vim được xử lý ở tầng ô nhập, nên nó không kích hoạt hành động ngắt thông thường). Phần lớn phím tắt `Ctrl+phím` vẫn được chuyển tới Claude Code như bình thường.

## Di chuyển (NORMAL mode)

| Phím | Motion |
|---|---|
| `h` `j` `k` `l` | Trái, xuống, lên, phải |
| `w` / `e` / `b` | Từ kế tiếp / cuối từ / từ trước |
| `0` / `$` / `^` | Đầu dòng / cuối dòng / ký tự không trắng đầu tiên |
| `gg` / `G` | Đầu / cuối ô nhập |
| `f{char}` / `t{char}` | Nhảy tới / ngay trước lần xuất hiện kế tiếp của một ký tự |

## Sửa (NORMAL mode)

| Phím | Hành động |
|---|---|
| `x` | Xoá ký tự dưới con trỏ |
| `dd` / `D` | Xoá dòng / tới cuối dòng |
| `dw` `de` `db` | Xoá từ, tới cuối từ, lùi một từ |
| `cc` / `C` | Thay dòng / tới cuối dòng |
| `yy` / `p` | Yank (sao chép) dòng / dán |
| `u` / `.` | Hoàn tác / lặp lại thay đổi gần nhất |
| `>>` / `<<` | Thụt / bỏ thụt dòng |

Operator kết hợp với [text object](^Một khoảng như một từ hoặc chuỗi trong ngoặc kép. Kết hợp với operator, ví dụ diw xoá phần trong của từ): `diw` xoá phần trong của từ, `ci"` thay văn bản bên trong ngoặc kép, `ya(` yank cả cặp ngoặc tròn.

## Escape nhanh hơn

Với tay tới `Esc` mãi cũng mỏi. Cài đặt `vimInsertModeRemaps` ánh xạ một chuỗi hai phím ở INSERT mode thành Escape. Kinh điển là `jj`:

```json
{
  "editorMode": "vim",
  "vimInsertModeRemaps": { "jj": "<Esc>" }
}
```

Gõ `j`, và một `j` thứ hai trong vòng một giây sẽ xoá chữ đầu và đưa bạn vào NORMAL mode. Dừng giữa hai lần gõ thì cả hai được giữ nguyên là chữ, nên những từ có hai chữ `j` liền nhau vẫn gõ được. `"<Esc>"` là đích duy nhất được hỗ trợ.

## Mẹo

- Bật vim mode trong `/config` ở mục Editor mode. Nó chỉ ảnh hưởng ô nhập prompt
- Motion vim không gán lại được qua [keybindings.json](^Hệ thống keybinding nằm phía trên tầng ô nhập văn bản. Xem mục Keybindings). Dùng `vimInsertModeRemaps` cho phím tắt ở INSERT mode
- Ở NORMAL mode, `/` mở tìm kiếm lịch sử giống `Ctrl+R`, và `?` hiện menu trợ giúp
- Ở mép ô nhập, `j` và `k` duyệt lịch sử lệnh thay vì di chuyển con trỏ

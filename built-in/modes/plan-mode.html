Plan Mode

Plan mode bảo Claude nghiên cứu và đề xuất thay đổi mà không thực hiện chúng. Claude đọc file, chạy lệnh shell để khám phá, và viết một kế hoạch, nhưng không sửa mã nguồn của bạn cho tới khi bạn duyệt. Đây là cách an toàn nhất để đưa Claude vào một codebase lạ hoặc một thay đổi rủi ro.

Vào Plan Mode

Ba cách vào:

Cách Khi nào dùng
Nhấn Shift+Tab Xoay vòng vào giữa phiên
Thêm /plan trước prompt Lập kế hoạch cho một prompt, rồi quay về chế độ trước
Khởi chạy bằng claude --permission-mode plan Bắt đầu cả phiên ở plan mode

Nhấn Shift+Tab lần nữa để rời plan mode mà không duyệt kế hoạch.

Claude được và không được làm gì

  • Được: đọc file, tìm kiếm, và chạy lệnh shell chỉ-đọcCác lệnh kiểm tra như ls, grep và git status. Claude Code giữ sẵn danh sách và chạy chúng thoải mái để hiểu code
  • Không được: sửa file nguồn. Việc sửa bị chặn cho tới khi bạn duyệt kế hoạch
  • Vẫn hỏi: lệnh shell sửa file như touch và rm vẫn xin duyệt, kể cả trong plan mode

Nếu Auto modeChế độ dùng bộ phân loại chạy nền để duyệt hành động an toàn. Xem mục Auto Mode khả dụng, Claude tự duyệt các lệnh khám phá chỉ-đọc mà không hỏi trong lúc lập kế hoạch. Tính năng này bật mặc định qua cài đặt useAutoModeDuringPlan. Việc sửa vẫn bị chặn trong cả hai trường hợp.

Review và duyệt kế hoạch

Khi kế hoạch sẵn sàng, Claude trình bày và hỏi bạn muốn tiếp tục thế nào. Các lựa chọn:

Lựa chọn Điều gì xảy ra
Yes, and use auto mode Duyệt và bắt đầu sửa ở Auto mode. Hiện là Yes, auto-accept edits khi Auto mode không khả dụng
Yes, manually approve edits Duyệt và review từng lần sửa
No, refine with Ultraplan Gửi kế hoạch sang UltraplanTrình review kế hoạch trên trình duyệt, thuộc Claude Code on the web để review
No, keep planning Ở lại plan mode và bảo Claude cần đổi gì

Duyệt kế hoạch sẽ thoát plan mode và chuyển phiên sang chế độ mà lựa chọn duyệt mô tả, để Claude bắt đầu sửa. Muốn lập kế hoạch lại, xoay vòng bằng Shift+Tab hoặc thêm /plan trước prompt tiếp theo.

Nhấn Ctrl+G để mở kế hoạch đề xuất trong editor và sửa trực tiếp trước khi Claude tiếp tục. Duyệt kế hoạch cũng đặt tên phiên theo nội dung kế hoạch, trừ khi bạn đã đặt tên.

{

    "defaultMode": "plan"
  }
}

# Plan Mode

Plan mode bảo Claude nghiên cứu và đề xuất thay đổi mà không thực hiện chúng. Claude đọc file, chạy lệnh shell để khám phá, và viết một kế hoạch, nhưng không sửa mã nguồn của bạn cho tới khi bạn duyệt. Đây là cách an toàn nhất để đưa Claude vào một codebase lạ hoặc một thay đổi rủi ro.

## Vào Plan Mode

Ba cách vào:

| Cách | Khi nào dùng |
|---|---|
| Nhấn `Shift+Tab` | Xoay vòng vào giữa phiên |
| Thêm `/plan` trước prompt | Lập kế hoạch cho một prompt, rồi quay về chế độ trước |
| Khởi chạy bằng `claude --permission-mode plan` | Bắt đầu cả phiên ở plan mode |

Nhấn `Shift+Tab` lần nữa để rời plan mode mà không duyệt kế hoạch.

## Claude được và không được làm gì

- **Được:** đọc file, tìm kiếm, và chạy [lệnh shell chỉ-đọc](^Các lệnh kiểm tra như ls, grep và git status. Claude Code giữ sẵn danh sách và chạy chúng thoải mái) để hiểu code
- **Không được:** sửa file nguồn. Việc sửa bị chặn cho tới khi bạn duyệt kế hoạch
- **Vẫn hỏi:** lệnh shell sửa file như `touch` và `rm` vẫn xin duyệt, kể cả trong plan mode

Nếu [Auto mode](^Chế độ dùng bộ phân loại chạy nền để duyệt hành động an toàn. Xem mục Auto Mode) khả dụng, Claude tự duyệt các lệnh khám phá chỉ-đọc mà không hỏi trong lúc lập kế hoạch. Tính năng này bật mặc định qua cài đặt `useAutoModeDuringPlan`. Việc sửa vẫn bị chặn trong cả hai trường hợp.

## Review và duyệt kế hoạch

Khi kế hoạch sẵn sàng, Claude trình bày và hỏi bạn muốn tiếp tục thế nào. Các lựa chọn:

| Lựa chọn | Điều gì xảy ra |
|---|---|
| **Yes, and use auto mode** | Duyệt và bắt đầu sửa ở Auto mode. Hiện là **Yes, auto-accept edits** khi Auto mode không khả dụng |
| **Yes, manually approve edits** | Duyệt và review từng lần sửa |
| **No, refine with Ultraplan** | Gửi kế hoạch sang [Ultraplan](^Trình review kế hoạch trên trình duyệt, thuộc Claude Code on the web) để review |
| **No, keep planning** | Ở lại plan mode và bảo Claude cần đổi gì |

Duyệt kế hoạch sẽ thoát plan mode và chuyển phiên sang chế độ mà lựa chọn duyệt mô tả, để Claude bắt đầu sửa. Muốn lập kế hoạch lại, xoay vòng bằng `Shift+Tab` hoặc thêm `/plan` trước prompt tiếp theo.

Nhấn `Ctrl+G` để mở kế hoạch đề xuất trong editor và sửa trực tiếp trước khi Claude tiếp tục. Duyệt kế hoạch cũng đặt tên phiên theo nội dung kế hoạch, trừ khi bạn đã đặt tên.

## Đặt Plan Mode làm mặc định

Để một dự án luôn bắt đầu ở plan mode, đặt `defaultMode` trong `.claude/settings.json`:

```json
{
  "permissions": {
    "defaultMode": "plan"
  }
}
```

## Khi nào dùng

- Bắt đầu với codebase bạn chưa quen và muốn có bản đồ trước khi thay đổi gì
- Khoanh phạm vi thay đổi lớn hoặc rủi ro để review hướng tiếp cận trước khi Claude bắt tay vào
- Biến một ý tưởng mơ hồ thành tập bước cụ thể, review được

## Mẹo

- `/plan` làm tiền tố một lần là cách nhanh nhất để lập kế hoạch cho một yêu cầu mà không đổi chế độ phiên
- Đọc kế hoạch trước khi duyệt. Giá trị của plan mode nằm ở bước review, nên hãy dùng nó
- Kết hợp plan mode với bối cảnh mới: lập kế hoạch, duyệt, rồi để Claude thực thi trong một lượt sạch sẽ

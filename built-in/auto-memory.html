Auto Memory

Mỗi phiên Claude Code bắt đầu với một context window trống. Auto memory là cách Claude tự mang kiến thức sang các phiên sau: nó ghi chú cho chính mình trong lúc làm việc, lệnh build đã học được, kinh nghiệm debug, khuôn mẫu đã nhận ra, sai lầm cần tránh, và đọc lại chúng khi bắt đầu các phiên sau.

Đây là bản đối ứng của CLAUDE.mdFile bạn viết để cho Claude chỉ dẫn lâu dài. Xem mục CLAUDE.md. Bạn viết CLAUDE.md; Claude viết auto memory. Cả hai đều được nạp khi bắt đầu mỗi cuộc hội thoại.

CLAUDE.md vs Auto Memory

CLAUDE.md Auto memory
Ai viết Bạn Claude
Chứa gì Chỉ dẫn và quy tắc Bài học và khuôn mẫu
Phạm vi Dự án, người dùng, hoặc tổ chức Theo repository, dùng chung giữa các worktree
Dùng cho Chuẩn code, quy trình, kiến trúc Lệnh build, kinh nghiệm debug, sở thích Claude phát hiện được

Dùng CLAUDE.md để chủ động định hướng hành vi của Claude. Auto memory để Claude học từ những lần bạn sửa mà bạn không phải ghi lại gì.

Nằm ở đâu

Mỗi dự án có thư mục bộ nhớ riêng:

~/.claude/projects/<project>/memory/
├── MEMORY.md          # Mục lục ngắn gọn, nạp mỗi phiên
├── debugging.md       # Ghi chú chi tiết theo một chủ đề
├── api-conventions.md # Một file chủ đề khác
└── ...
  • Đường dẫn <project> được suy ra từ git repositoryNên mọi worktree và thư mục con của cùng một repo dùng chung một thư mục bộ nhớ, hoặc từ gốc dự án khi bạn không ở trong git repo
  • MEMORY.md là mục lục. Claude giữ nó ngắn và chuyển chi tiết sang các file chủ đề
  • Auto memory chỉ nằm trên máy. Nó không được chia sẻ giữa các máy hay với nhóm, khác với CLAUDE.md đã commit

Cách được nạp

200 dòng hoặc 25KB đầu tiên của MEMORY.md, tuỳ cái nào đến trước, được nạp khi bắt đầu mỗi cuộc hội thoại. Các file chủ đề như debugging.md không được nạp từ đầu. Claude đọc chúng khi cần.

Vì chỉ phần đầu của MEMORY.md được nạp tự động, Claude Code nhắc Claude giữ mục lục gọn: mỗi mục một dòng, chi tiết đẩy sang file chủ đề, mục cũ được gộp hoặc bỏ. Điều này giữ phần luôn được nạp ở mức nhỏ.

Khi bạn thấy Saved 2 memories hoặc Recalled 2 memories trên giao diện, Claude đang ghi vào hoặc đọc từ thư mục này.

Quản lý bằng /memory

Chạy /memory để:

  • Liệt kê vị trí CLAUDE.md, CLAUDE.local.md và auto memory
  • Bật hoặc tắt auto memory
  • Mở thư mục auto memory, hoặc bất kỳ file nào, trong editor

Mọi thứ đều là markdown thuần mà bạn có thể đọc, sửa hoặc xoá bất cứ lúc nào. Để xác nhận thứ gì thực sự đã được nạp vào phiên hiện tại, chạy /contextLệnh cho thấy những gì đang có trong context window, gồm cả mục Memory files. Xem mục Context & Thinking.

Bảo Claude nhớ điều gì

Bạn không cần chờ Claude tự quyết định. Cứ bảo nó:

  • "Nhớ rằng test API cần một Redis instance chạy local" sẽ lưu vào auto memory
  • "Thêm cái này vào CLAUDE.md" sẽ đưa vào CLAUDE.md

Claude không lưu thứ gì đó trong mọi phiên. Nó quyết định điều gì đáng giữ dựa trên việc thông tin đó có giúp ích cho cuộc hội thoại sau hay không.

Bật hoặc tắt

Auto memory bật mặc định. Để thay đổi:

Mục tiêu Cách làm
Bật/tắt Dùng công tắc trong /memory (lưu autoMemoryEnabled vào settings người dùng)
Tắt cho một dự án Đặt "autoMemoryEnabled": false trong settings của dự án đó
Tắt ở mọi nơi Đặt biến môi trường CLAUDE_CODE_DISABLE_AUTO_MEMORY=1
Lưu ở nơi khác Đặt autoMemoryDirectory thành đường dẫn tuyệt đối trong settings

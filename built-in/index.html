Built-in là gì?

Các tính năng đi kèm Claude Code, không cần thiết lập.

built-in/BUILT-IN.md

Tính năng tích hợp sẵn

Mọi thứ phía trên đường kẻ là hệ sinh thái .claude/: file cấu hình, skills, agents, hooks và plugins mà bạn tạo và tuỳ biến cho dự án. Đó là những thứ bạn tự xây.

Phần này thì khác. Đây là các tính năng đi kèm Claude Code và không cần thiết lập. Chúng tồn tại dù bạn có thư mục .claude/ hay không. Bạn không cấu hình chúng, không tạo file cho chúng, và không commit chúng vào git. Chúng luôn ở đó, sẵn sàng để dùng.

Bạn sẽ tìm thấy gì ở đây

Chế độ (Modes)

Claude tự làm bao nhiêu trước khi hỏi bạn. Xoay vòng bằng Shift+Tab.

  • Manual - duyệt mọi hành động trước khi chạy
  • Accept Edits - để Claude sửa file, bạn review sau
  • Plan - nghiên cứu và đề xuất trước khi đụng vào code
  • Auto - chạy tự do với bộ phân loại an toàn chạy nền

Auto Memory

Ghi chú Claude tự viết cho mình qua các phiên: lệnh build, kinh nghiệm debug, và sở thích nó phát hiện. Bản đối ứng của các file CLAUDE.md do bạn viết. Quản lý bằng /memory.

Context & Thinking

Thứ gì lấp đầy context window của Claude, cách xem bằng /context, và cách giải phóng chỗ bằng /compact. Cùng với mức effort và ultrathink để điều chỉnh độ sâu suy luận của Claude.

Bàn phím & Phím tắt

Các phím tắt điều khiển phiên từ bàn phím, cách gán lại bất kỳ phím nào, và trình soạn prompt kiểu vim.

  • Esc - ngắt Claude giữa lượt và chuyển hướng
  • Shift+Tab - xoay vòng chế độ quyền
  • Ctrl+B - đưa tác vụ đang chạy xuống nền
  • Ctrl+R - tìm ngược trong lịch sử lệnh

CLI & Headless

Cách bạn khởi chạy claude từ terminal, các cờ đáng biết, và claude -p để chạy Claude không tương tác trong script và CI.

  • claude -p "query" - in kết quả rồi thoát
  • --model, --effort - chọn model và mức độ suy nghĩ
  • --permission-mode - khởi động ở chế độ đã chọn
  • --output-format json - đầu ra có cấu trúc cho script

Bundled Skills

Quy trình dựa trên prompt có sẵn trong mọi phiên Claude Code. Khác với skill tuỳ chỉnh bạn tạo trong .claude/skills/, chúng do Anthropic duy trì và dùng được ngay.

  • /simplify - Review và dọn dẹp thay đổi gần đây
  • /batch - Điều phối thay đổi song song quy mô lớn
  • /debug - Chẩn đoán phiên hiện tại
  • /loop - Chạy prompt theo chu kỳ định kỳ
  • /claude-api - Nạp tài liệu API và SDK cho ngôn ngữ của bạn

Lệnh tích hợp

Các lệnh slash cài sẵn trong Claude Code, chạy logic cố định trực tiếp. Quản lý phiên, cấu hình, chẩn đoán, tích hợp và hơn nữa. Hơn 50 lệnh được sắp theo nhóm.

  • /compact - Nén hội thoại để giải phóng bối cảnh
  • /btw - Hỏi câu bên lề mà không làm rối lịch sử
  • /diff - Trình xem tương tác cho thay đổi chưa commit
  • /init - Tạo CLAUDE.md khởi đầu từ codebase
  • /rewind - Khôi phục hội thoại và code về một điểm trước đó

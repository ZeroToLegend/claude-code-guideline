/permissions

Xem và quản lý quyền công cụ của Claude Code. Nó liệt kê mọi rule quyền và cho biết mỗi rule đến từ file settings.json nào.

Cách dùng

/permissions

Mở giao diện quyền, nơi bạn xem Claude được phép và bị chặn làm gì, và thêm hoặc sửa rule.

Ba loại rule

Quyền được biểu diễn bằng các rule trong file settings:

Rule Tác dụng
allow Duyệt trước một công cụ hoặc lệnh để nó không bao giờ hỏi
ask Buộc hỏi, kể cả khi một chế độ rộng hơn không hỏi
deny Chặn thẳng, ở mọi chế độ

Rule được đánh giá theo thứ tự: deny, rồi ask, rồi allow. Rule khớp đầu tiên thắng, và mức cụ thể không thay đổi thứ tự. Một deny rộng như Bash(aws *) chặn cả lời gọi khớp với một allow hẹp hơn, nên rule deny không thể mang ngoại lệ kiểu danh sách cho phép.

Cú pháp rule

Mẫu Khớp với
Bash(npm run build) Đúng lệnh đó
Bash(npm run *) Mọi lệnh bắt đầu bằng npm run
Read(./.env) Đọc file .env
Edit(src/**) Sửa bất cứ gì trong src/
WebFetch(domain:example.com) Tải dữ liệu từ domain đó
Agent(isolation:worktree) Rule deny hoặc ask có thể khớp theo tham số đầu vào của công cụ

# /permissions

Xem và quản lý quyền công cụ của Claude Code. Nó liệt kê mọi rule quyền và cho biết mỗi rule đến từ file `settings.json` nào.

## Cách dùng

```
/permissions
```

Mở giao diện quyền, nơi bạn xem Claude được phép và bị chặn làm gì, và thêm hoặc sửa rule.

## Ba loại rule

Quyền được biểu diễn bằng các rule trong file settings:

| Rule | Tác dụng |
|---|---|
| `allow` | Duyệt trước một công cụ hoặc lệnh để nó không bao giờ hỏi |
| `ask` | Buộc hỏi, kể cả khi một chế độ rộng hơn không hỏi |
| `deny` | Chặn thẳng, ở mọi chế độ |

Rule được đánh giá theo thứ tự: **deny, rồi ask, rồi allow.** Rule khớp đầu tiên thắng, và mức cụ thể không thay đổi thứ tự. Một `deny` rộng như `Bash(aws *)` chặn cả lời gọi khớp với một `allow` hẹp hơn, nên rule deny không thể mang ngoại lệ kiểu danh sách cho phép.

## Cú pháp rule

| Mẫu | Khớp với |
|---|---|
| `Bash(npm run build)` | Đúng lệnh đó |
| `Bash(npm run *)` | Mọi lệnh bắt đầu bằng `npm run ` |
| `Read(./.env)` | Đọc file `.env` |
| `Edit(src/**)` | Sửa bất cứ gì trong `src/` |
| `WebFetch(domain:example.com)` | Tải dữ liệu từ domain đó |
| `Agent(isolation:worktree)` | Rule deny hoặc ask có thể khớp theo tham số đầu vào của công cụ |

## Do Claude Code cưỡng chế, không phải model

Rule quyền là ranh giới cứng. Chỉ dẫn trong prompt hay CLAUDE.md định hình điều Claude cố làm, nhưng không thể thay đổi điều Claude Code cho phép. Để cấp hoặc thu hồi quyền, dùng `/permissions`, một [chế độ quyền](^Mức nền quyết định hành động nào cần hỏi. Xem mục Chế độ), hoặc một hook PreToolUse.

## Recently Denied

Khi một hành động bị chặn, nó xuất hiện ở tab **Recently denied** trong `/permissions`, nơi bạn có thể thử lại với duyệt thủ công.

## Mẹo

- Dùng rule `deny` khi cần bảo đảm. Nó mạnh hơn mọi chế độ, vì chế độ không thể nới lỏng nó
- Duyệt trước các lệnh an toàn, hay dùng, như `Bash(npm test)`, bằng rule `allow` để giảm số lần hỏi
- Rule nằm trong file settings, nên bạn có thể commit một bộ dùng chung cho nhóm hoặc giữ bộ cá nhân ở local

/diff

Mở trình xem diff tương tác, hiện thay đổi chưa commit trong thư mục làm việc và diff theo từng lượt từ các chỉnh sửa của Claude.

Cách dùng

/diff

Không có tham số. Trình xem mở ngay lập tức.

Cách hoạt động

  1. /diff khởi chạy một trình xem diff trên terminal
  2. Dùng mũi tên trái/phải để chuyển giữa hai chế độ xem:
    • Git diff: mọi thay đổi chưa commit trong thư mục làm việc
    • Turn diffs: thay đổi Claude đã làm trong từng lượt
  3. Dùng mũi tên lên/xuống để duyệt file trong chế độ xem hiện tại
  4. Nhấn Escape hoặc q để đóng

Hai chế độ xem

Chế độ xem Hiện gì Hữu ích cho
Git diff Mọi thay đổi chưa commit (đã và chưa stage) Review tất cả trước khi commit
Turn diffs Thay đổi của từng lượt Claude, riêng rẽ Hiểu Claude đã đổi gì và khi nào

Khi nào dùng

  • Trước khi commit, để review mọi thay đổi Claude đã làm
  • Để biết lượt nào đã đưa vào một thay đổi cụ thể
  • Để xác nhận Claude đã sửa đúng file trước khi đi tiếp
  • Khi bạn muốn kiểm tra nhanh bằng mắt mà không rời phiên

Mẹo

  • /diff hiện cùng thông tin như git diff nhưng trong trình xem tương tác, duyệt được
  • Turn diffs đặc biệt hữu ích sau phiên dài với nhiều chỉnh sửa, khi chỉ git diff không cho biết bước nào đã đổi gì
  • Kết hợp với /rewind nếu bạn thấy thay đổi muốn hoàn tác: dùng /diff để tìm lượt, rồi /rewind để quay về đó

/rewind vs Git

/rewind không thay thế git. Nó dùng git bên dưới (quay về một commit checkpoint), nhưng còn khôi phục cả trạng thái hội thoại. Dùng /rewind khi bạn muốn hoàn tác cả thay đổi code lẫn cuộc hội thoại đã tạo ra chúng. Dùng git checkout hoặc git stash khi bạn chỉ muốn hoàn tác thay đổi code.

Mẹo

  • Checkpoint là tự động. Bạn không cần tạo thủ công
  • /rewind hiệu quả nhất với thay đổi gần đây. Với lịch sử cũ hơn, dùng git trực tiếp
  • Kết hợp với /diff để xem từng lượt đã đổi gì trước khi quyết định quay về đâu
  • Nhấn Esc hai lần làm phím tắt nhanh thay vì gõ /rewind

# /rewind

Khôi phục hội thoại và code về một điểm trước đó trong phiên. Claude Code tạo [checkpoint](^Ảnh chụp tự động trạng thái git trước khi Claude thay đổi. Mỗi checkpoint ghi lại lượt hội thoại và trạng thái working tree) trước khi thay đổi, nên bạn có thể yên tâm hoàn tác và thử hướng khác.

## Cách dùng

```
/rewind
```

Không có tham số. Một bộ chọn tương tác mở ra, hiện lịch sử hội thoại.

Bạn cũng có thể kích hoạt rewind bằng cách nhấn `Esc` hai lần.

## Cách hoạt động

1. Claude Code hiện danh sách các lượt hội thoại, mỗi lượt kèm tóm tắt điều đã xảy ra
2. Bạn chọn điểm muốn quay về

4. Bạn tiếp tục hội thoại từ điểm đã khôi phục

## Thứ gì được khôi phục

| Được khôi phục | Không được khôi phục |
|---|---|
| Thay đổi file (qua git checkout) | Tác dụng phụ bên ngoài (lời gọi API, tin nhắn đã gửi) |

## Khi nào dùng

- Claude đi sai hướng và bạn muốn thử cách khác

- Bạn lỡ duyệt một thay đổi không mong muốn

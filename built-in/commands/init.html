/init

Phân tích codebase và tạo file CLAUDE.md khởi đầu. Đây là cách nhanh nhất để cho Claude bối cảnh lâu dài về dự án.

Cách dùng

/init

Không có tham số. Claude xem xét dự án và soạn file.

Cách hoạt động

  1. Claude quét cấu trúc dự án, file cấu hình, README và script build
  2. Nó soạn CLAUDE.md gồm: tổng quan dự án, tech stack, lệnh build và test, quy ước code, và quy trình thường dùng
  3. Bản nháp được mở để bạn review
  4. Bạn sửa, duyệt và commit nó vào git

Nó tạo ra gì

Kết quả /init điển hình gồm:

  • Tổng quan dự án: dự án là gì, tech stack, các thư mục chính
  • Lệnh build và test: cách build, test, lint và deploy
  • Quy ước code: khuôn mẫu đặt tên, import, xử lý lỗi nó phát hiện được
  • Quy trình thường dùng: đặt tên nhánh, quy trình PR, các bước deploy
  • Lưu ý: những điểm kỳ quặc hoặc yêu cầu nó nhận thấy

Với dự án có sẵn

/init dùng được với dự án đã có CLAUDE.md. Thay vì ghi đè, nó:

  • Phân tích những gì đã có
  • Đề xuất bổ sung và cải tiến
  • Giữ nguyên chỉ dẫn hiện có của bạn

Điều này khiến nó hữu ích cho bảo trì định kỳ: chạy /init sau thay đổi lớn để xem Claude có phát hiện quy ước hay quy trình mới đáng ghi lại không.

Khi nào dùng

  • Thiết lập Claude Code cho một dự án mới lần đầu
  • Onboard thành viên muốn có điểm khởi đầu CLAUDE.md nhanh
  • Sau refactor lớn hoặc đổi tech stack, để làm mới bối cảnh dự án
  • Khi Claude cứ mắc cùng một lỗi và bạn muốn thêm một quy tắc

Mẹo

  • Review kỹ những gì /init tạo ra. Đó là điểm khởi đầu, không phải sản phẩm cuối
  • Bổ sung những gì Claude không tự suy ra được: URL deploy, quy ước nhóm, cạm bẫy đã biết
  • Giữ CLAUDE.md dưới 200 dòng. Chuyển tài liệu chi tiết sang các file @import
  • Commit vào git để cả nhóm dùng chung bối cảnh

```
/init
```

3. Bản nháp được mở để bạn review
4. Bạn sửa, duyệt và commit nó vào git

- **Tổng quan dự án**: dự án là gì, tech stack, các thư mục chính

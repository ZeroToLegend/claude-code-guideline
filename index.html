Sổ tay Claude Code

Hướng dẫn Claude Code bằng tiếng Việt: từ cài đặt đầu tiên tới thiết lập cho cả nhóm. Phần Hướng dẫn giải thích vì sao và khi nào; phần Tham chiếu mô phỏng một dự án thật, mỗi file là một khái niệm của Claude Code.

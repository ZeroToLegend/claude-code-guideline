Học Claude Code
bằng cách khám phá.

Đây là một dự án Claude Code mô phỏng. Mỗi file và thư mục ở thanh bên là một khái niệm thật của Claude Code — đúng thư mục .claude/, các file cấu hình và khung mẫu bạn sẽ gặp trong một repo thực tế. Bấm vào bất kỳ file nào để biết nó làm gì, cách thiết lập, và xem ví dụ có chú thích bạn có thể chép vào dự án của mình.

Mở file. Đọc nguồn. Học. Xây dựng.

CLAUDE.mdCách Claude ghi nhớ ngữ cảnh giữa các phiên. Bộ nhớ lâu dài của dự án.Cài đặt & QuyềnCấu hình hành vi của Claude, quyền truy cập công cụ và hàng rào an toàn.RulesQuy ước theo ngữ cảnh mà Claude tự nạp dựa trên file bạn đang sửa.Lệnh Slash tuỳ chỉnhlỗi thờiQuy trình đã lưu, gọi bằng một phím gõ.SkillsDạy Claude kiến thức chuyên biệt mà nó tự nạp khi cần.MCP ServersKết nối Claude với công cụ, API và dịch vụ bên ngoài qua một giao thức chuẩn.HooksTự động chạy script tuỳ chỉnh trước hoặc sau khi Claude gọi công cụ.AgentsTạo subagent chuyên biệt và điều phối agent team làm việc song song.PluginsĐóng gói skills, agents, hooks và MCP server thành tiện ích chia sẻ được.ModsHook JavaScript sống trong phiên của bạn: theo dõi sự kiện, viết lại hoặc chặn chúng, và vẽ UI tuỳ chỉnh.Output StylesĐổi vai trò, giọng điệu và định dạng trả lời của Claude cho cả phiên, bằng style có sẵn hoặc tự viết.Dynamic WorkflowsScript JavaScript điều phối hàng chục subagent; lưu lại thành lệnh /<tên> để chạy lại.MarketplacesPhân phối và khám phá plugin qua các danh mục được tuyển chọn.WorktreesChạy các phiên song song trong git worktree riêng và tự chép file gitignore cần thiết vào đó.Bundled SkillsQuy trình dựa trên prompt có sẵn trong mọi phiên Claude Code.Lệnh tích hợpCác lệnh slash cài sẵn trong Claude Code, chạy logic cố định trực tiếp.Chế độ (Modes)Kiểm soát Claude tự làm bao nhiêu: duyệt từng hành động, chấp nhận chỉnh sửa, lập kế hoạch trước, hoặc giao hẳn kèm kiểm tra an toàn.Auto MemoryCách Claude tự ghi chú cho mình giữa các phiên và đọc lại. Bản đối ứng của CLAUDE.md.Context & ThinkingThứ gì lấp đầy context window của Claude, cách xem và giải phóng nó, và cách điều chỉnh độ sâu suy nghĩ.Bàn phím & Phím tắtCác phím tắt có sẵn trong mọi phiên, cách tuỳ biến, và trình soạn prompt kiểu vim.CLI & HeadlessCách khởi chạy claude từ terminal: tương tác hay print mode, các cờ quan trọng, và chạy headless cho script và CI.Thư mục ~/.claudeCấu hình cá nhân cho mọi dự án, ~/.claude.json, managed settings và dữ liệu Claude Code tự ghi ra.

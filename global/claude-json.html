~/.claude.json

File trạng thái mà Claude Code tự ghi cho chính nó. Lưu ý vị trí: file nằm ngay trong thư mục home (~/.claude.json), không nằm trong ~/.claude/. Bạn không cần sửa tay file này.

Nội dung Ví dụ
Thông tin tài khoản Tài khoản đang đăng nhập, gói đăng ký
MCP server cá nhân Server thêm bằng claude mcp add -s local hoặc -s user

Các khoá global config

Một số cài đặt chỉ có hiệu lực từ ~/.claude.json, không từ settings.json. Bạn đổi chúng qua /config (hoặc /config key=value):

Khoá Tác dụng
autoConnectIde Tự kết nối với VS Code hoặc JetBrains đang chạy khi mở từ terminal ngoài
autoInstallIdeExtension Tắt việc tự cài extension IDE khi chạy trong terminal của VS Code
claudeInChromeDefaultEnabled Bật tích hợp Chrome khi bắt đầu phiên
copyFullResponse /copy chép cả câu trả lời mà không hiện bộ chọn
copyOnSelect Tắt việc tự chép văn bản khi bôi đen bằng chuột ở chế độ toàn màn hình
defaultToAgentsView Chạy claude không tham số sẽ mở agent view thay vì hội thoại mới
diffTool Thay đổi file đề xuất mở trong trình xem diff của IDE hay ở lại terminal
externalEditorContext Hiện câu trả lời cuối của Claude dưới dạng comment khi nhấn Ctrl+G
leftArrowOpensAgents Tắt phím ← đưa phiên xuống nền và mở agent view
prStatusFooterEnabled Tắt huy hiệu trạng thái review PR ở chân ô prompt

Phân biệt với các file settings

File Ai ghi Dùng cho
~/.claude/settings.json Bạn hoặc /config Cài đặt người dùng: quyền, hooks, model, theme…
.claude/settings.json Nhóm Cài đặt dự án dùng chung
.claude/settings.local.json Bạn hoặc Claude Code Ghi đè cá nhân cho một dự án

Khi file bị hỏng

Nếu ~/.claude.json không đọc được, Claude Code chép bản hỏng sang ~/.claude/backups/.claude.json.corrupted.<thời-gian> và hỏi bạn muốn thoát để sửa tay hay đặt lại cấu hình mặc định. Để khôi phục trạng thái cũ, chép lại một trong năm file .claude.json.backup.<thời-gian> gần nhất trong ~/.claude/backups/. Claude Code lưu bản backup này mỗi lần trước khi ghi file.

Mẹo

  • Đừng xoá file này: bạn sẽ mất thông tin tài khoản, MCP server cá nhân và trạng thái tin cậy của các dự án
  • claude purge <đường-dẫn> xoá mục của một dự án trong file này mà không đụng phần còn lại
  • Muốn MCP server cho cả nhóm, dùng .mcp.json trong dự án thay vì phạm vi local hay user

# ~/.claude.json

File trạng thái mà **Claude Code tự ghi cho chính nó**. Lưu ý vị trí: file nằm ngay trong thư mục home (`~/.claude.json`), không nằm trong `~/.claude/`. Bạn không cần sửa tay file này.

## Chứa gì

| Nội dung | Ví dụ |
|---|---|
| Thông tin tài khoản | Tài khoản đang đăng nhập, gói đăng ký |
| MCP server cá nhân | Server thêm bằng `claude mcp add -s local` hoặc `-s user` |
| Trạng thái theo từng dự án | Quyết định [tin cậy thư mục](^Hộp thoại xác nhận bạn tin một thư mục, hiện lần đầu chạy Claude Code ở đó), lịch sử, MCP server của dự án |
| Các khoá global config | Tuỳ chọn mà `/config` ghi cho bạn |
| Bật/tắt giao diện | Các lựa chọn giao diện đã lưu |

## Các khoá global config

Một số cài đặt chỉ có hiệu lực từ `~/.claude.json`, không từ `settings.json`. Bạn đổi chúng qua `/config` (hoặc `/config key=value`):

| Khoá | Tác dụng |
|---|---|
| `autoConnectIde` | Tự kết nối với VS Code hoặc JetBrains đang chạy khi mở từ terminal ngoài |
| `autoInstallIdeExtension` | Tắt việc tự cài extension IDE khi chạy trong terminal của VS Code |
| `claudeInChromeDefaultEnabled` | Bật tích hợp Chrome khi bắt đầu phiên |
| `copyFullResponse` | `/copy` chép cả câu trả lời mà không hiện bộ chọn |
| `copyOnSelect` | Tắt việc tự chép văn bản khi bôi đen bằng chuột ở chế độ toàn màn hình |
| `defaultToAgentsView` | Chạy `claude` không tham số sẽ mở agent view thay vì hội thoại mới |
| `diffTool` | Thay đổi file đề xuất mở trong trình xem diff của IDE hay ở lại terminal |
| `externalEditorContext` | Hiện câu trả lời cuối của Claude dưới dạng comment khi nhấn `Ctrl+G` |
| `leftArrowOpensAgents` | Tắt phím `←` đưa phiên xuống nền và mở agent view |
| `prStatusFooterEnabled` | Tắt huy hiệu trạng thái review PR ở chân ô prompt |

## Phân biệt với các file settings

| File | Ai ghi | Dùng cho |
|---|---|---|
| `~/.claude/settings.json` | Bạn hoặc `/config` | Cài đặt người dùng: quyền, hooks, model, theme… |
| `.claude/settings.json` | Nhóm | Cài đặt dự án dùng chung |
| `.claude/settings.local.json` | Bạn hoặc Claude Code | Ghi đè cá nhân cho một dự án |
| **`~/.claude.json`** | **Claude Code** | **Trạng thái app, tài khoản, MCP cá nhân, global config** |

## Khi file bị hỏng

Nếu `~/.claude.json` không đọc được, Claude Code chép bản hỏng sang `~/.claude/backups/.claude.json.corrupted.<thời-gian>` và hỏi bạn muốn thoát để sửa tay hay đặt lại cấu hình mặc định. Để khôi phục trạng thái cũ, chép lại một trong năm file `.claude.json.backup.<thời-gian>` gần nhất trong `~/.claude/backups/`. Claude Code lưu bản backup này mỗi lần trước khi ghi file.

## Mẹo

- Đừng xoá file này: bạn sẽ mất thông tin tài khoản, MCP server cá nhân và trạng thái tin cậy của các dự án
- `claude purge <đường-dẫn>` xoá mục của một dự án trong file này mà không đụng phần còn lại
- Muốn MCP server cho cả nhóm, dùng `.mcp.json` trong dự án thay vì phạm vi local hay user

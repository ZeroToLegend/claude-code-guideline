Thư mục ~/.claude

Mọi thứ phía trên mô phỏng thư mục dự án: những file bạn commit để cả nhóm dùng chung. Phần này là thư mục home của bạn: ~/.claude/ chứa cấu hình cá nhân áp cho mọi dự án, và cả dữ liệu Claude Code tự ghi ra trong lúc làm việc.

Trên Windows, ~/.claude là %USERPROFILE%\.claude. Nếu bạn đặt biến CLAUDE_CONFIG_DIR, mọi đường dẫn ~/.claude chuyển vào thư mục đó.

Phần lớn người dùng chỉ sửa CLAUDE.md và settings.json. Phần còn lại là tuỳ chọn: thêm skills, rules hay subagent khi thật sự cần.

Cùng tên, hai phạm vi

Hầu hết file trong .claude/ của dự án cũng có bản ở ~/.claude/. Bản dự án dùng chung qua git; bản home chỉ của bạn nhưng áp cho mọi dự án.

~/.claude/
├── CLAUDE.md                   # Chỉ dẫn cá nhân cho mọi dự án
├── settings.json               # Cài đặt người dùng
├── keybindings.json            # Phím tắt tuỳ chỉnh        (chỉ có ở home)
├── rules/  skills/  commands/  agents/  output-styles/  workflows/
├── agent-memory/<agent>/       # Bộ nhớ subagent phạm vi user
├── themes/*.json               # Theme màu tuỳ chỉnh       (chỉ có ở home)
├── plugins/                    # Plugin đã cài, marketplace đã clone
└── projects/<project>/memory/  # Auto memory               (chỉ có ở home)
~/.claude.json                  # Trạng thái app, tài khoản, MCP cá nhân

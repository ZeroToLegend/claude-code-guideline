managed-settings.json

Cài đặt do tổ chức triển khai lên máy của mọi lập trình viên. Claude Code áp chúng trên mọi cấp khác, nên không file người dùng, dự án, local hay giá trị --settings nào ghi đè được (trừ vài ngoại lệ bảo mật mà giá trị chặt hơn từ cấp thấp vẫn được tôn trọng).

Bạn không tạo hay sửa file này. Trang này giúp bạn biết nó có tồn tại không, nằm ở đâu, và vì sao một cài đặt của bạn không có tác dụng.

Ví dụ

json
{
  "permissions": {
    "deny": [
      "Read(./.env)",
      "Read(./secrets/**)"
    ],
    "disableBypassPermissionsMode": "disable"
  },
  "allowManagedPermissionRulesOnly": true
}

File này chặn đọc hai loại file, tắt chế độ bypass, và khiến Claude Code bỏ qua rule quyền từ file người dùng, dự án, local và từ --allowedTools.

Nằm ở đâu

Hệ điều hành Thư mục hệ thống
macOS /Library/Application Support/ClaudeCode/
Linux và WSL /etc/claude-code/
Windows C:\Program Files\ClaudeCode\

Trong thư mục đó có thể có managed-settings.json, thư mục managed-settings.d/ (mỗi nhóm một file, gộp theo thứ tự chữ cái như 10-telemetry.json, 20-security.json), managed-mcp.json cho MCP server được quản lý, và một CLAUDE.md cấp tổ chức.

Bốn cách tổ chức triển khai

Cách Triển khai thế nào Khi nào Claude Code đọc
Server-managed Trang quản trị claude.ai hoặc Claude apps gateway Lúc khởi động và mỗi giờ
MDM / chính sách hệ điều hành Configuration profile trên macOS, registry HKLM trên Windows (Jamf, Intune, Group Policy…) Lúc khởi động và kiểm tra mỗi 30 phút
File managed-settings.json trong thư mục hệ thống Lúc khởi động và khi file thay đổi
Registry HKCU (Windows, WSL) Giá trị trong HKCU Chỉ khi không có nguồn quản trị nào ở trên

Khi có nhiều nguồn, mặc định Claude Code dùng nguồn xếp hạng cao nhất có ít nhất một khoá chính sách và bỏ qua các nguồn còn lại (thứ tự: server → MDM → file → HKCU).

Vị trí trong thứ tự ưu tiên

  1. Managed settings ← cao nhất
  2. Dòng lệnh (--settings)
  3. .claude/settings.local.json
  4. .claude/settings.json
  5. ~/.claude/settings.json

Kiểm tra tổ chức đang áp gì

Chạy /status trong Claude Code. Dòng Setting sources cho biết nguồn managed nào đang áp cho bạn, ví dụ Enterprise managed settings (file). Nếu một cài đặt bạn đặt không có tác dụng và /status có nguồn managed, rất có thể tổ chức đã khoá nó. Khi đó chỉ quản trị viên đổi được.

Mẹo

  • Một model trong managed settings chỉ là giá trị khởi đầu; khoá thật sự là availableModels và deniedModels
  • Danh sách (như permissions.deny) từ managed được gộp với danh sách của bạn, trừ khi tổ chức đặt allowManagedPermissionRulesOnly
  • Phiên chạy trên cloud chỉ nhận server-managed settings, không đọc file hay MDM trên máy bạn

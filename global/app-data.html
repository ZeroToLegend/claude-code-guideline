Dữ liệu ứng dụng

Ngoài cấu hình bạn viết, ~/.claude/ còn chứa dữ liệu Claude Code tự ghi ra trong các phiên: transcript, lịch sử prompt, ảnh chụp file trước khi sửa, cache và log. Trang này cho biết thứ gì nằm ở đâu, khi nào bị dọn, và cách xoá.

Các file này là văn bản thuần, không mã hoá. Mọi thứ đi qua một công cụ đều được ghi vào transcript trên đĩa: nội dung file, output lệnh, văn bản bạn dán. Nếu Claude đọc file .env, giá trị trong đó nằm trong transcript.

Tự động dọn dẹp

Claude Code xoá các mục dưới đây khi chúng cũ hơn cleanupPeriodDays (mặc định 30 ngày, tối thiểu 1).

Đường dẫn trong ~/.claude/ Nội dung
projects/<project>/<session>.jsonl Transcript đầy đủ: mọi tin nhắn, lời gọi công cụ và kết quả
projects/<project>/<session>/subagents/ Transcript của subagent
projects/<project>/<session>/tool-results/ Output công cụ lớn được tách ra file riêng
file-history/<session>/ Ảnh chụp file trước khi Claude sửa, dùng cho checkpoint và /rewind
plans/ File kế hoạch viết trong plan mode
debug/ Debug log từng phiên, khi chạy --debug hoặc /debug
paste-cache/ Nội dung các lần dán lớn
uploads/<session>/ File đính kèm từ web hoặc mobile khi dùng Remote Control
dev-mods/<session>/ Mod mà Claude viết trong phiên
tasks/ Danh sách việc do công cụ task ghi
shell-snapshots/ Alias, hàm và tuỳ chọn shell chụp lúc khởi động
backups/ Các bản cũ của ~/.claude.json (giữ 5 bản mới nhất)
usage-data/ Báo cáo của /insights
skills/.trash/, plugins/.trash/ Skill và plugin đồng bộ từ claude.ai đã bị gỡ, để còn khôi phục được

Ngoại lệ:

  • sessions/: mỗi phiên đang chạy một file nhỏ, xoá khi phiên kết thúc
  • Auto memory trong projects/<project>/memory/ không bị dọn theo tuổi
  • Transcript của Claude Desktop và Cowork được giữ bất kể tuổi; đặt desktopSessionCleanupPeriodDays để giới hạn
  • Bare mode (claude -p --bare) không chạy lượt dọn dẹp

Thư mục scratchpad

Mỗi phiên có một thư mục tạm để Claude để file trung gian, script phụ và bản nháp không thuộc về dự án. Khi Claude nói đã lưu gì đó "vào scratchpad", file nằm ở đây. Claude tạo, sửa và đọc file trong đó mà không cần xin quyền.

Hệ điều hành Đường dẫn
macOS /private/tmp/claude-<uid>/<project>/<session-id>/scratchpad/
Linux /tmp/claude-<uid>/<project>/<session-id>/scratchpad/
Windows %TEMP%\claude\<project>\<session-id>\scratchpad\

Scratchpad nằm trong thư mục tạm của hệ thống, không nằm trong ~/.claude, và hệ điều hành có thể xoá nó (ví dụ khi khởi động lại). Muốn giữ thứ gì Claude viết ở đó, hãy nhờ Claude chuyển vào dự án. Chỉ có khi bạn đăng nhập bằng tài khoản claude.ai và dùng Anthropic API.

Giữ cho tới khi bạn tự xoá

Đường dẫn Nội dung
history.jsonl Các prompt bạn đã gõ, dùng cho phím mũi tên lên, Ctrl+R và tự hoàn thành lệnh !
stats-cache.json Tổng token và chi phí hiển thị trong /usage
remote-settings.json Bản cache của server-managed settings (xoá khi đăng xuất)
cache/changelog.md Bản cache changelog cho /release-notes

File trạng thái cần giữ, đừng xoá:

  • .credentials.json: thông tin đăng nhập
  • agent-memory/: bộ nhớ của subagent
  • jobs/ và daemon/: trạng thái phiên chạy nền

Và không bao giờ xoá ~/.claude.json, ~/.claude/settings.json hay ~/.claude/plugins/: chúng chứa tài khoản, tuỳ chọn và plugin đã cài.

Xoá dữ liệu của một dự án: claude purge

bash
claude purge ~/work/my-repo --dry-run   # xem trước, chưa xoá gì
claude purge ~/work/my-repo             # xoá, có hỏi xác nhận
claude purge ~/work/my-repo --yes       # xoá không hỏi, cho script
claude purge --all                      # xoá cho mọi dự án

Lệnh này xoá: transcript và auto memory trong projects/, các mục tasks/, debug/, file-history/ theo phiên, các dòng prompt tương ứng trong history.jsonl, và mục của dự án trong ~/.claude.json. Nó in toàn bộ kế hoạch xoá và hỏi xác nhận trước. Bỏ đường dẫn để chọn dự án từ danh sách; thêm -i để duyệt từng mục.

Trước v2.1.288, lệnh tên là claude project purge.
